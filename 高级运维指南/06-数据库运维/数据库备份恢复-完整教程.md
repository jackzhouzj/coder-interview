## 1. 备份恢复基础

### 1.1 备份类型

```yaml
# 按备份方式分类

完全备份（Full Backup）:
  定义: 备份所有数据
  优点:
    - 恢复简单快速
    - 数据完整性好
  缺点:
    - 备份时间长
    - 占用空间大
    - 对系统影响大
  适用场景:
    - 数据量小
    - 定期基础备份
    - 重要数据

增量备份（Incremental Backup）:
  定义: 只备份自上次备份后变化的数据
  优点:
    - 备份速度快
    - 占用空间小
  缺点:
    - 恢复复杂
    - 需要完整备份链
  适用场景:
    - 数据量大
    - 频繁备份
    - 变化数据少

差异备份（Differential Backup）:
  定义: 备份自上次完全备份后变化的数据
  优点:
    - 恢复相对简单
    - 备份速度较快
  缺点:
    - 占用空间逐渐增大
  适用场景:
    - 介于完全和增量之间
    - 需要平衡恢复速度和空间
```

```yaml
# 按备份方式分类

逻辑备份（Logical Backup）:
  定义: 导出SQL语句或数据文件
  工具:
    - MySQL: mysqldump
    - PostgreSQL: pg_dump
    - MongoDB: mongodump
  优点:
    - 可读性好
    - 跨平台
    - 可选择性备份
  缺点:
    - 速度慢
    - 占用空间大
  适用场景:
    - 数据迁移
    - 跨版本恢复
    - 部分数据备份

物理备份（Physical Backup）:
  定义: 直接复制数据文件
  工具:
    - MySQL: XtraBackup
    - PostgreSQL: pg_basebackup
    - 文件系统快照
  优点:
    - 速度快
    - 占用空间小
  缺点:
    - 平台依赖
    - 不可读
  适用场景:
    - 大数据量
    - 快速恢复
    - 整库备份
```

### 1.2 备份策略

```yaml
# 3-2-1备份原则

3份副本:
  - 1份生产数据
  - 2份备份副本

2种介质:
  - 本地磁盘
  - 远程存储/云存储

1份异地:
  - 异地机房
  - 云端存储
  - 防止区域性灾难
```

### 1.3 RTO和RPO

```yaml
# 恢复目标

RTO（Recovery Time Objective）:
  定义: 恢复时间目标
  说明: 系统从故障到恢复正常的最大可接受时间
  示例:
    - RTO = 1小时: 必须在1小时内恢复
    - RTO = 4小时: 必须在4小时内恢复

RPO（Recovery Point Objective）:
  定义: 恢复点目标
  说明: 可接受的最大数据丢失量
  示例:
    - RPO = 0: 不能丢失任何数据
    - RPO = 1小时: 可接受丢失1小时内的数据
    - RPO = 24小时: 可接受丢失1天内的数据

关系:
  - RTO越小，恢复成本越高
  - RPO越小，备份频率越高
  - 需要根据业务需求平衡
```

## 2. MySQL备份恢复

### 2.1 mysqldump备份

```bash
# 1. 备份单个数据库
mysqldump -h localhost -u root -p \
    --single-transaction \
    --routines \
    --triggers \
    --events \
    mydb > mydb_$(date +%Y%m%d).sql

# 2. 备份所有数据库
mysqldump -h localhost -u root -p \
    --all-databases \
    --single-transaction \
    --routines \
    --triggers \
    --events > all_databases_$(date +%Y%m%d).sql

# 3. 备份特定表
mysqldump -h localhost -u root -p \
    mydb users orders > tables_$(date +%Y%m%d).sql

# 4. 只备份表结构
mysqldump -h localhost -u root -p \
    --no-data \
    mydb > schema_$(date +%Y%m%d).sql

# 5. 只备份数据
mysqldump -h localhost -u root -p \
    --no-create-info \
    mydb > data_$(date +%Y%m%d).sql

# 6. 压缩备份
mysqldump -h localhost -u root -p \
    --single-transaction \
    mydb | gzip > mydb_$(date +%Y%m%d).sql.gz

# 参数说明：
# --single-transaction: InnoDB一致性备份
# --routines: 备份存储过程和函数
# --triggers: 备份触发器
# --events: 备份事件
# --master-data=2: 记录binlog位置（注释形式）
# --flush-logs: 刷新日志
```

### 2.2 XtraBackup物理备份

```bash
# 1. 安装XtraBackup
yum install -y percona-xtrabackup-80

# 2. 完全备份
xtrabackup --backup \
    --user=root \
    --password=password \
    --target-dir=/backup/full_$(date +%Y%m%d)

# 3. 增量备份
# 基于完全备份的增量
xtrabackup --backup \
    --user=root \
    --password=password \
    --target-dir=/backup/inc1_$(date +%Y%m%d) \
    --incremental-basedir=/backup/full_20240201

# 4. 准备备份
xtrabackup --prepare \
    --target-dir=/backup/full_20240201

# 5. 准备增量备份
xtrabackup --prepare \
    --apply-log-only \
    --target-dir=/backup/full_20240201

xtrabackup --prepare \
    --apply-log-only \
    --target-dir=/backup/full_20240201 \
    --incremental-dir=/backup/inc1_20240202

# 6. 恢复数据
systemctl stop mysqld
rm -rf /var/lib/mysql/*
xtrabackup --copy-back \
    --target-dir=/backup/full_20240201
chown -R mysql:mysql /var/lib/mysql
systemctl start mysqld
```

### 2.4 MySQL备份脚本

```bash
#!/bin/bash
# MySQL自动备份脚本

# 配置
MYSQL_HOST="localhost"
MYSQL_USER="root"
MYSQL_PASS="password"
BACKUP_DIR="/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=7

# 创建备份目录
mkdir -p $BACKUP_DIR

# 获取所有数据库
databases=$(mysql -h $MYSQL_HOST -u $MYSQL_USER -p$MYSQL_PASS \
    -e "SHOW DATABASES;" | grep -Ev "(Database|information_schema|performance_schema|mysql|sys)")

# 备份每个数据库
for db in $databases; do
    echo "备份数据库: $db"
    
    mysqldump -h $MYSQL_HOST -u $MYSQL_USER -p$MYSQL_PASS \
        --single-transaction \
        --routines \
        --triggers \
        --events \
        --master-data=2 \
        $db | gzip > $BACKUP_DIR/${db}_$DATE.sql.gz
    
    if [ $? -eq 0 ]; then
        echo "  成功: ${db}_$DATE.sql.gz"
    else
        echo "  失败: $db"
    fi
done

# 清理旧备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +$RETENTION_DAYS -delete

echo "备份完成: $DATE"
```

## 3. PostgreSQL备份恢复

### 3.1 pg_dump备份

```bash
# 1. 备份单个数据库
pg_dump -h localhost -U postgres -d mydb \
    -F c -f /backup/mydb_$(date +%Y%m%d).dump

# 2. 备份所有数据库
pg_dumpall -h localhost -U postgres \
    -f /backup/all_$(date +%Y%m%d).sql

# 3. 备份特定表
pg_dump -h localhost -U postgres -d mydb \
    -t users -F c -f /backup/users_$(date +%Y%m%d).dump

# 4. 备份特定schema
pg_dump -h localhost -U postgres -d mydb \
    -n app -F c -f /backup/app_$(date +%Y%m%d).dump

# 5. 只备份表结构
pg_dump -h localhost -U postgres -d mydb \
    --schema-only -F c -f /backup/schema_$(date +%Y%m%d).dump

# 6. 只备份数据
pg_dump -h localhost -U postgres -d mydb \
    --data-only -F c -f /backup/data_$(date +%Y%m%d).dump

# 参数说明：
# -F c: custom格式（推荐）
# -F p: plain SQL格式
# -F t: tar格式
# -F d: directory格式
```

### 3.2 pg_basebackup物理备份

```bash
# 1. 基础备份
pg_basebackup -h localhost -U postgres \
    -D /backup/base_$(date +%Y%m%d) \
    -Ft -z -P -X stream

# 2. 配置WAL归档
# postgresql.conf
wal_level = replica
archive_mode = on
archive_command = 'cp %p /backup/wal_archive/%f'

# 3. 创建恢复配置
cat > /var/lib/pgsql/15/data/recovery.conf << EOF
restore_command = 'cp /backup/wal_archive/%f %p'
recovery_target_time = '2024-02-01 12:00:00'
EOF
```

### 3.3 PostgreSQL恢复

```bash
# 1. 恢复完整备份
pg_restore -h localhost -U postgres \
    -d mydb -c /backup/mydb_20240201.dump

# 2. 恢复特定表
pg_restore -h localhost -U postgres \
    -d mydb -t users /backup/mydb_20240201.dump

# 3. 恢复SQL格式备份
psql -h localhost -U postgres -d mydb \
    -f /backup/all_20240201.sql

# 4. 并行恢复
pg_restore -h localhost -U postgres \
    -d mydb -j 4 /backup/mydb_20240201.dump

# 5. PITR恢复
# 停止PostgreSQL
systemctl stop postgresql-15

# 清空数据目录
rm -rf /var/lib/pgsql/15/data/*

# 解压基础备份
tar -xzf /backup/base_20240201/base.tar.gz \
    -C /var/lib/pgsql/15/data/

# 创建recovery.signal
touch /var/lib/pgsql/15/data/recovery.signal

# 配置恢复参数
cat >> /var/lib/pgsql/15/data/postgresql.auto.conf << EOF
restore_command = 'cp /backup/wal_archive/%f %p'
recovery_target_time = '2024-02-01 12:00:00'
recovery_target_action = 'promote'
EOF

# 启动PostgreSQL
systemctl start postgresql-15
```

### 3.4 PostgreSQL备份脚本

```bash
#!/bin/bash
# PostgreSQL自动备份脚本

# 配置
PG_HOST="localhost"
PG_PORT="5432"
PG_USER="postgres"
BACKUP_DIR="/backup/postgresql"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=7

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份所有数据库
pg_dumpall -h $PG_HOST -p $PG_PORT -U $PG_USER \
    -f $BACKUP_DIR/all_databases_$DATE.sql

# 压缩备份
gzip $BACKUP_DIR/all_databases_$DATE.sql

# 备份单个数据库（custom格式）
for db in mydb appdb; do
    echo "备份数据库: $db"
    
    pg_dump -h $PG_HOST -p $PG_PORT -U $PG_USER \
        -d $db -F c -f $BACKUP_DIR/${db}_$DATE.dump
    
    if [ $? -eq 0 ]; then
        echo "  成功: ${db}_$DATE.dump"
    else
        echo "  失败: $db"
    fi
done

# 清理旧备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +$RETENTION_DAYS -delete
find $BACKUP_DIR -name "*.dump" -mtime +$RETENTION_DAYS -delete

echo "备份完成: $DATE"
```

### 5.4 Redis备份脚本

```bash
#!/bin/bash
# Redis自动备份脚本

# 配置
REDIS_HOST="127.0.0.1"
REDIS_PORT="6379"
REDIS_PASS="password"
BACKUP_DIR="/backup/redis"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=7

# 创建备份目录
mkdir -p $BACKUP_DIR

# 触发BGSAVE
redis-cli -h $REDIS_HOST -p $REDIS_PORT -a $REDIS_PASS BGSAVE

# 等待BGSAVE完成
while true; do
    result=$(redis-cli -h $REDIS_HOST -p $REDIS_PORT -a $REDIS_PASS \
        INFO persistence | grep rdb_bgsave_in_progress)
    
    if echo "$result" | grep -q "rdb_bgsave_in_progress:0"; then
        break
    fi
    
    sleep 1
done

# 复制RDB文件
cp /var/lib/redis/dump.rdb $BACKUP_DIR/dump_$DATE.rdb

# 压缩备份
gzip $BACKUP_DIR/dump_$DATE.rdb

# 清理旧备份
find $BACKUP_DIR -name "dump_*.rdb.gz" \
    -mtime +$RETENTION_DAYS -delete

echo "备份完成: dump_$DATE.rdb.gz"
```


## 6. 备份策略设计

### 6.1 完全备份+增量备份策略

```yaml
# 策略1：每周完全+每日增量

周日:
  类型: 完全备份
  时间: 凌晨2:00
  保留: 4周
  
周一至周六:
  类型: 增量备份
  时间: 凌晨3:00

恢复流程:
  1. 恢复最近的完全备份
  2. 按顺序恢复所有增量备份
  
优点:
  - 平衡备份时间和空间
  - 恢复相对简单
  
缺点:
  - 需要完整备份链
```

```yaml
# 策略2：每日完全+每小时增量

每日:
  类型: 完全备份
  时间: 凌晨1:00
  保留: 7天
  
每小时:
  类型: 增量备份
  时间: 每小时整点
  保留: 24小时
  
恢复流程:
  1. 恢复当天的完全备份
  2. 恢复需要的增量备份
  
优点:
  - RPO可达1小时
  - 恢复链短
  
缺点:
  - 备份频繁
  - 占用资源多
```

### 6.2 备份窗口设计

```python
#!/usr/bin/env python3
# 备份窗口计算脚本

import datetime

class BackupWindow:
    def __init__(self, data_size_gb, backup_speed_mbps):
        self.data_size_gb = data_size_gb
        self.backup_speed_mbps = backup_speed_mbps
    
    def calculate_time(self):
        """计算备份时间"""
        data_size_mb = self.data_size_gb * 1024
        backup_time_seconds = data_size_mb / self.backup_speed_mbps
        backup_time_hours = backup_time_seconds / 3600
        
        return {
            'seconds': backup_time_seconds,
            'minutes': backup_time_seconds / 60,
            'hours': backup_time_hours
        }
    
    def suggest_window(self, business_hours_start=8, business_hours_end=22):
        """建议备份窗口"""
        backup_time = self.calculate_time()
        
        # 计算可用窗口
        available_hours = 24 - (business_hours_end - business_hours_start)
        
        if backup_time['hours'] <= available_hours:
            start_time = business_hours_end
            end_time = (start_time + int(backup_time['hours']) + 1) % 24
            
            return {
                'feasible': True,
                'start': f"{start_time:02d}:00",
                'end': f"{end_time:02d}:00",
                'duration': backup_time
            }
        else:
            return {
                'feasible': False,
                'required_hours': backup_time['hours'],
                'available_hours': available_hours,
                'suggestion': '考虑增量备份或提升备份速度'
            }

# 使用示例
backup = BackupWindow(data_size_gb=500, backup_speed_mbps=100)
result = backup.calculate_time()
print(f"备份时间: {result['hours']:.2f}小时")

window = backup.suggest_window()
print(f"建议窗口: {window}")
```

```python
#!/usr/bin/env python3
# 并行备份脚本

import subprocess
import concurrent.futures
import logging
from datetime import datetime

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

class ParallelBackup:
    def __init__(self, max_workers=4):
        self.max_workers = max_workers
        self.backup_dir = "/backup/mysql"
        self.date = datetime.now().strftime("%Y%m%d_%H%M%S")
    
    def backup_database(self, db_name):
        """备份单个数据库"""
        try:
            backup_file = f"{self.backup_dir}/{db_name}_{self.date}.sql.gz"
            
            cmd = [
                "mysqldump",
                "-h", "localhost",
                "-u", "root",
                "-ppassword",
                "--single-transaction",
                "--routines",
                "--triggers",
                "--events",
                db_name
            ]
            
            # 执行备份
            with open(backup_file, 'wb') as f:
                p1 = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
                p2 = subprocess.Popen(['gzip'], stdin=p1.stdout, stdout=f)
                p1.stdout.close()
                p2.communicate()
            
            if p2.returncode == 0:
                logging.info(f"成功备份: {db_name}")
                return {'db': db_name, 'status': 'success', 'file': backup_file}
            else:
                logging.error(f"备份失败: {db_name}")
                return {'db': db_name, 'status': 'failed'}
        
        except Exception as e:
            logging.error(f"备份异常: {db_name} - {str(e)}")
            return {'db': db_name, 'status': 'error', 'message': str(e)}
    
    def get_databases(self):
        """获取数据库列表"""
        cmd = [
            "mysql",
            "-h", "localhost",
            "-u", "root",
            "-ppassword",
            "-e", "SHOW DATABASES;"
        ]
        
        result = subprocess.run(cmd, capture_output=True, text=True)
        databases = result.stdout.strip().split('\n')[1:]
        
        # 过滤系统数据库
        exclude = ['information_schema', 'performance_schema', 'mysql', 'sys']
        return [db for db in databases if db not in exclude]
    
    def run(self):
        """执行并行备份"""
        databases = self.get_databases()
        logging.info(f"开始并行备份 {len(databases)} 个数据库，并发数: {self.max_workers}")
        
        results = []
        with concurrent.futures.ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            futures = {executor.submit(self.backup_database, db): db for db in databases}
            
            for future in concurrent.futures.as_completed(futures):
                result = future.result()
                results.append(result)
        
        # 统计结果
        success = sum(1 for r in results if r['status'] == 'success')
        failed = len(results) - success
        
        logging.info(f"备份完成: 成功 {success}, 失败 {failed}")
        return results

if __name__ == '__main__':
    backup = ParallelBackup(max_workers=4)
    backup.run()
```

```python
            logging.info(f"完整性检查: {backup_file} - 通过")
            return True
        except Exception as e:
            logging.error(f"完整性检查: {backup_file} - 失败: {str(e)}")
            return False
    
    def check_age(self, backup_file, max_age_hours=48):
        """检查文件时间"""
        if not os.path.exists(backup_file):
            return False
        
        file_time = datetime.fromtimestamp(os.path.getmtime(backup_file))
        age = datetime.now() - file_time
        passed = age.total_seconds() / 3600 <= max_age_hours
        
        logging.info(f"时间检查: {backup_file} - {age.total_seconds()/3600:.1f}小时 - {'通过' if passed else '失败'}")
        return passed
    
    def check_restore(self, backup_file):
        """检查恢复功能"""
        try:
            # 创建测试数据库
            conn = mysql.connector.connect(**self.mysql_config)
            cursor = conn.cursor()
            
            cursor.execute(f"DROP DATABASE IF EXISTS {self.test_db}")
            cursor.execute(f"CREATE DATABASE {self.test_db}")
            conn.commit()
            
            # 恢复备份
            cmd = f"gunzip -c {backup_file} | mysql -h {self.mysql_config['host']} " \
                  f"-u {self.mysql_config['user']} -p{self.mysql_config['password']} {self.test_db}"
            
            result = subprocess.run(cmd, shell=True, capture_output=True)
            
            if result.returncode == 0:
                # 验证表数量
                cursor.execute(f"SELECT COUNT(*) FROM information_schema.tables "
                             f"WHERE table_schema='{self.test_db}'")
                table_count = cursor.fetchone()[0]
                
                # 清理
                cursor.execute(f"DROP DATABASE {self.test_db}")
                conn.commit()
                
                passed = table_count > 0
                logging.info(f"恢复检查: {backup_file} - {table_count}个表 - {'通过' if passed else '失败'}")
                return passed
            else:
                logging.error(f"恢复检查: {backup_file} - 失败")
                return False
        
        except Exception as e:
            logging.error(f"恢复检查异常: {backup_file} - {str(e)}")
            return False
        finally:
            if 'conn' in locals():
                conn.close()
    
    def validate_all(self):
        """验证所有备份文件"""
        results = []
        
        for filename in os.listdir(self.backup_dir):
            if filename.endswith('.sql.gz'):
                backup_file = os.path.join(self.backup_dir, filename)
                passed, checks = self.validate_file(backup_file)
                
                results.append({
                    'file': filename,
                    'passed': passed,
                    'checks': checks
                })
        
        return results
    
    def generate_report(self, results):
        """生成验证报告"""
        total = len(results)
        passed = sum(1 for r in results if r['passed'])
        failed = total - passed
        
        report = f"""
备份验证报告
============
时间: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}
总计: {total}个备份文件
通过: {passed}个
失败: {failed}个

详细结果:
"""
        
        for result in results:
            status = "✓" if result['passed'] else "✗"
            report += f"\n{status} {result['file']}\n"
            
            for check, passed in result['checks'].items():
                check_status = "✓" if passed else "✗"
                report += f"  {check_status} {check}\n"
        
        return report
```

```python
#!/usr/bin/env python3
# Python版本的S3备份脚本

import boto3
import subprocess
from datetime import datetime
import os

class S3Backup:
    def __init__(self, bucket_name, region='us-west-2'):
        self.s3_client = boto3.client('s3', region_name=region)
        self.bucket_name = bucket_name
        self.backup_dir = '/backup/mysql'
    
    def backup_database(self, db_name, mysql_config):
        """备份数据库到S3"""
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
        backup_file = f"{self.backup_dir}/{db_name}_{timestamp}.sql.gz"
        
        # 执行mysqldump
        cmd = [
            'mysqldump',
            '-h', mysql_config['host'],
            '-u', mysql_config['user'],
            f"-p{mysql_config['password']}",
            '--single-transaction',
            '--routines',
            '--triggers',
            '--events',
            db_name
        ]
        
        with open(backup_file, 'wb') as f:
            p1 = subprocess.Popen(cmd, stdout=subprocess.PIPE)
            p2 = subprocess.Popen(['gzip'], stdin=p1.stdout, stdout=f)
            p1.stdout.close()
            p2.communicate()
        
        # 上传到S3
        s3_key = f"mysql/{db_name}/{os.path.basename(backup_file)}"
        
        try:
            self.s3_client.upload_file(
                backup_file,
                self.bucket_name,
                s3_key,
                ExtraArgs={
                    'StorageClass': 'STANDARD_IA',
                    'ServerSideEncryption': 'AES256'
                }
            )
            print(f"上传成功: {s3_key}")
            
            # 删除本地文件
            os.remove(backup_file)
            
            return True
        except Exception as e:
            print(f"上传失败: {str(e)}")
            return False
    
    def list_backups(self, db_name):
        """列出S3中的备份"""
        prefix = f"mysql/{db_name}/"
        
        response = self.s3_client.list_objects_v2(
            Bucket=self.bucket_name,
            Prefix=prefix
        )
        
        if 'Contents' in response:
            for obj in response['Contents']:
                print(f"{obj['Key']} - {obj['Size']} bytes - {obj['LastModified']}")
    
    def restore_from_s3(self, s3_key, local_path):
        """从S3恢复备份"""
        try:
            self.s3_client.download_file(
                self.bucket_name,
                s3_key,
                local_path
            )
            print(f"下载成功: {local_path}")
            return True
        except Exception as e:
            print(f"下载失败: {str(e)}")
            return False

# 使用示例
if __name__ == '__main__':
    mysql_config = {
        'host': 'localhost',
        'user': 'root',
        'password': 'password'
```

```python
#!/usr/bin/env python3
# 高级备份监控脚本

import os
import time
import smtplib
import requests

from email.mime.text import MIMEText
import mysql.connector

class BackupMonitor:
    def __init__(self, config):

        self.mysql_config = config['mysql']
        self.alert_config = config['alert']
        self.thresholds = config['thresholds']
    
    def check_all(self):

            'backup_size': self.check_backup_size(),
            'backup_age': self.check_backup_age(),
            'storage_space': self.check_storage_space(),
            'backup_integrity': self.check_backup_integrity(),
            'backup_consistency': self.check_backup_consistency()
        }
        
        return results
    
    def check_backup_exists(self):
        """检查备份文件是否存在"""
        today = datetime.now().strftime('%Y%m%d')
        backup_files = []
        
        for root, dirs, files in os.walk(self.backup_dir):
            for file in files:
                if today in file and file.endswith('.sql.gz'):
                    backup_files.append(os.path.join(root, file))
        
        if not backup_files:
            self.send_alert('CRITICAL', '今日未发现备份文件')
            return False
        
        return True
    
    def check_backup_size(self):
        """检查备份文件大小"""
        issues = []
        
        for root, dirs, files in os.walk(self.backup_dir):
            for file in files:
                if file.endswith('.sql.gz'):
                    file_path = os.path.join(root, file)
                    size_mb = os.path.getsize(file_path) / (1024 * 1024)
                    
                    if size_mb < self.thresholds['min_size_mb']:
                        issues.append(f"{file}: {size_mb:.2f}MB")
        
        if issues:
            self.send_alert('WARNING', f"备份文件过小:\n" + "\n".join(issues))
            return False
        
        return True
    
    def check_backup_age(self):
        """检查备份时间"""
        max_age = timedelta(hours=self.thresholds['max_age_hours'])
        issues = []
        
        for db_dir in os.listdir(self.backup_dir):
            db_path = os.path.join(self.backup_dir, db_dir)
            
            if os.path.isdir(db_path):
                files = [f for f in os.listdir(db_path) if f.endswith('.sql.gz')]
                
                if not files:
                    issues.append(f"{db_dir}: 无备份文件")
                    continue
                
                latest_file = max(files, key=lambda f: os.path.getmtime(os.path.join(db_path, f)))
                file_path = os.path.join(db_path, latest_file)
                file_time = datetime.fromtimestamp(os.path.getmtime(file_path))
                age = datetime.now() - file_time
                
                if age > max_age:
                    issues.append(f"{db_dir}: {age.total_seconds()/3600:.1f}小时未备份")
        
        if issues:
            self.send_alert('CRITICAL', "备份过旧:\n" + "\n".join(issues))
            return False
        
        return True
    
    def check_storage_space(self):
        """检查存储空间"""
        stat = os.statvfs(self.backup_dir)
        usage = (1 - stat.f_bavail / stat.f_blocks) * 100
        
        if usage > self.thresholds['storage_critical']:
            self.send_alert('CRITICAL', f"存储空间严重不足: {usage:.1f}%")
            return False
        elif usage > self.thresholds['storage_warning']:
            self.send_alert('WARNING', f"存储空间不足: {usage:.1f}%")
            return False
        
        return True
    
    def check_backup_integrity(self):
        """检查备份完整性"""
        issues = []
        
        for root, dirs, files in os.walk(self.backup_dir):
            for file in files:
                if file.endswith('.sql.gz'):
                    file_path = os.path.join(root, file)
                    
                    # 检查gzip完整性
                    if os.system(f"gzip -t {file_path} 2>/dev/null") != 0:
                        issues.append(file)
        
        if issues:
            self.send_alert('CRITICAL', "备份文件损坏:\n" + "\n".join(issues))
            return False
        
        return True
    
    def check_backup_consistency(self):
        """检查备份一致性"""
        try:
            conn = mysql.connector.connect(**self.mysql_config)
            cursor = conn.cursor()
            
            # 获取数据库列表
            cursor.execute("SHOW DATABASES")
            databases = [db[0] for db in cursor.fetchall() 
                        if db[0] not in ('information_schema', 'performance_schema', 'mysql', 'sys')]
            
            # 检查每个数据库是否有备份
            missing = []
            for db in databases:
                db_backup_dir = os.path.join(self.backup_dir, db)
                if not os.path.exists(db_backup_dir) or not os.listdir(db_backup_dir):
                    missing.append(db)
            
            if missing:
                self.send_alert('WARNING', f"以下数据库缺少备份:\n" + "\n".join(missing))
                return False
            
            return True
        
        except Exception as e:
            self.send_alert('ERROR', f"一致性检查失败: {str(e)}")
            return False
        finally:
            if 'conn' in locals():
                conn.close()
    
    def send_alert(self, level, message):
        """发送告警"""
        timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        full_message = f"[{timestamp}] [{level}] {message}"
        
        print(full_message)
        
        # 发送邮件
        if 'email' in self.alert_config:
            self.send_email(level, full_message)
        
        # 发送Webhook
        if 'webhook' in self.alert_config:
            self.send_webhook(level, full_message)
    
    def send_email(self, level, message):
        """发送邮件告警"""
        msg = MIMEText(message)
        msg['Subject'] = f"[{level}] 备份监控告警"
        msg['From'] = self.alert_config['email']['from']
        msg['To'] = self.alert_config['email']['to']
        
        try:
            server = smtplib.SMTP(self.alert_config['email']['smtp_server'])
            server.send_message(msg)
            server.quit()
        except Exception as e:
            print(f"邮件发送失败: {str(e)}")
    
    def send_webhook(self, level, message):
        """发送Webhook告警"""
        try:
            requests.post(
                self.alert_config['webhook']['url'],
                json={'text': message}
            )
        except Exception as e:
            print(f"Webhook发送失败: {str(e)}")

# 配置示例
config = {
    'backup_dir': '/backup/mysql',
    'mysql': {
        'host': 'localhost',
        'user': 'root',
        'password': 'password'
    },
    'alert': {

            'smtp_server': 'smtp.example.com',

            'to': 'admin@example.com'
        },
        'webhook': {

    },

    }
```

### 12.3 案例3：跨版本数据库迁移

```yaml
场景描述:
  - 源数据库: MySQL 5.7
  - 目标数据库: MySQL 8.0
  - 数据量: 500GB
  - 要求: 最小化停机时间

迁移步骤:
  1. 评估兼容性
  2. 准备目标环境
  3. 全量数据迁移
  4. 增量数据同步
  5. 切换验证
```

```bash
#!/bin/bash
# 跨版本数据库迁移脚本

SOURCE_HOST="mysql57-server"
TARGET_HOST="mysql80-server"
BACKUP_DIR="/backup/migration"
DATE=$(date +%Y%m%d_%H%M%S)

log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1"
}

# 1. 兼容性检查
log "执行兼容性检查..."
mysqlcheck --host=$SOURCE_HOST -u root -ppassword \
    --all-databases \
    --check-upgrade > $BACKUP_DIR/compatibility_check_$DATE.log

# 2. 全量备份
log "执行全量备份..."
mysqldump --host=$SOURCE_HOST -u root -ppassword \
    --all-databases \
    --single-transaction \
    --routines \
    --triggers \
    --events \
    --master-data=2 | gzip > $BACKUP_DIR/full_migration_$DATE.sql.gz

# 3. 恢复到目标数据库
log "恢复到目标数据库..."
gunzip -c $BACKUP_DIR/full_migration_$DATE.sql.gz | \
    mysql --host=$TARGET_HOST -u root -ppassword

# 4. 配置主从复制（用于增量同步）
log "配置主从复制..."

# 在源数据库创建复制用户
mysql --host=$SOURCE_HOST -u root -ppassword << EOF
CREATE USER 'repl'@'%' IDENTIFIED BY 'repl_password';
GRANT REPLICATION SLAVE ON *.* TO 'repl'@'%';
FLUSH PRIVILEGES;
EOF

# 获取binlog位置
BINLOG_FILE=$(grep "CHANGE MASTER TO" $BACKUP_DIR/full_migration_$DATE.sql | \
    sed -n "s/.*MASTER_LOG_FILE='\([^']*\)'.*/\1/p")
BINLOG_POS=$(grep "CHANGE MASTER TO" $BACKUP_DIR/full_migration_$DATE.sql | \
    sed -n "s/.*MASTER_LOG_POS=\([0-9]*\).*/\1/p")

# 在目标数据库配置复制
mysql --host=$TARGET_HOST -u root -ppassword << EOF
CHANGE MASTER TO
    MASTER_HOST='$SOURCE_HOST',
    MASTER_USER='repl',
    MASTER_PASSWORD='repl_password',
    MASTER_LOG_FILE='$BINLOG_FILE',
    MASTER_LOG_POS=$BINLOG_POS;
START SLAVE;
EOF

# 5. 监控复制延迟
log "监控复制延迟..."
while true; do
    DELAY=$(mysql --host=$TARGET_HOST -u root -ppassword \
        -e "SHOW SLAVE STATUS\G" | grep "Seconds_Behind_Master" | awk '{print $2}')
    
    if [ "$DELAY" == "0" ]; then
        log "复制已同步"
        break
    else
        log "复制延迟: ${DELAY}秒"
        sleep 10
    fi
done

# 6. 停止应用写入
log "停止应用写入..."
systemctl stop myapp

# 7. 等待最终同步
log "等待最终同步..."
sleep 30

# 8. 停止复制
log "停止复制..."
mysql --host=$TARGET_HOST -u root -ppassword -e "STOP SLAVE"

# 9. 数据验证
log "数据验证..."
SOURCE_COUNT=$(mysql --host=$SOURCE_HOST -u root -ppassword \
    -e "SELECT SUM(table_rows) FROM information_schema.tables WHERE table_schema NOT IN ('information_schema','performance_schema','mysql','sys')" -s -N)

TARGET_COUNT=$(mysql --host=$TARGET_HOST -u root -ppassword \
    -e "SELECT SUM(table_rows) FROM information_schema.tables WHERE table_schema NOT IN ('information_schema','performance_schema','mysql','sys')" -s -N)

log "源数据库行数: $SOURCE_COUNT"
log "目标数据库行数: $TARGET_COUNT"

if [ "$SOURCE_COUNT" == "$TARGET_COUNT" ]; then
    log "数据验证通过"
else
    log "数据验证失败"
    exit 1
fi

# 10. 更新应用配置
log "更新应用配置..."
sed -i "s/$SOURCE_HOST/$TARGET_HOST/g" /etc/myapp/database.conf

# 11. 启动应用
log "启动应用..."
systemctl start myapp

log "迁移完成"
```
