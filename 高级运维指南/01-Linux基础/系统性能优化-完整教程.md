### CPU性能优化策略

**1. 进程优先级调整**
```bash
# 查看进程优先级
ps -eo pid,ni,pri,comm

# 调整进程nice值（-20到19，越小优先级越高）
nice -n 10 ./my_program          # 启动时设置
renice -n -5 -p 1234              # 运行时调整

# 实时优先级（需要root权限）
chrt -f 50 ./critical_program     # FIFO调度
chrt -r 50 ./critical_program     # RR调度
```

**2. CPU亲和性设置**
```bash
# 查看进程CPU亲和性
taskset -p 1234

# 设置进程绑定到特定CPU
taskset -c 0,1 ./my_program       # 绑定到CPU 0和1
taskset -cp 0-3 1234              # 将进程1234绑定到CPU 0-3

# 在代码中设置CPU亲和性（C语言）
```

```c
#include <sched.h>
#include <pthread.h>

void set_cpu_affinity() {
    cpu_set_t cpuset;
    CPU_ZERO(&cpuset);
    CPU_SET(0, &cpuset);  // 绑定到CPU 0
    
    pthread_t thread = pthread_self();
    pthread_setaffinity_np(thread, sizeof(cpu_set_t), &cpuset);
}
```

**3. CPU调度策略优化**
```bash
# 查看当前调度策略
chrt -p 1234

# 设置调度策略
# SCHED_OTHER: 默认分时调度
# SCHED_FIFO: 实时先进先出
# SCHED_RR: 实时轮转
# SCHED_BATCH: 批处理
# SCHED_IDLE: 空闲时运行

chrt -b 0 ./batch_job             # 批处理任务
chrt -i 0 ./low_priority_job      # 低优先级任务
```

**4. 中断优化**
```bash
# 查看中断分布
cat /proc/interrupts

# 查看软中断
cat /proc/softirqs

# 设置网卡中断亲和性
echo 1 > /proc/irq/30/smp_affinity  # 绑定到CPU 0
echo 2 > /proc/irq/31/smp_affinity  # 绑定到CPU 1

# 使用irqbalance自动平衡中断
systemctl start irqbalance
```

**2. 内存分配和回收**
```bash
# 查看内存分配统计
vmstat 1
# si: swap in (从磁盘换入内存)
# so: swap out (从内存换出到磁盘)

# 查看slab缓存
slabtop

# 查看内存碎片
cat /proc/buddyinfo
```

### 内存优化策略

**1. Swap优化**
```bash
# 查看swap使用
swapon -s

# 调整swappiness（0-100，越小越不倾向使用swap）
# 默认60，建议服务器设置为10
cat /proc/sys/vm/swappiness
echo 10 > /proc/sys/vm/swappiness

# 永久生效
echo "vm.swappiness = 10" >> /etc/sysctl.conf
sysctl -p

# 清理swap
swapoff -a && swapon -a
```

**2. 内存缓存优化**
```bash
# 清理页面缓存
sync
echo 1 > /proc/sys/vm/drop_caches

# 清理dentries和inodes
echo 2 > /proc/sys/vm/drop_caches

# 清理所有缓存
echo 3 > /proc/sys/vm/drop_caches

# 注意：生产环境慎用，会影响性能
```

**3. 大页内存（Huge Pages）**
```bash
# 查看大页配置
cat /proc/meminfo | grep Huge

# 配置大页
echo 1024 > /proc/sys/vm/nr_hugepages

# 永久配置
echo "vm.nr_hugepages = 1024" >> /etc/sysctl.conf

# 透明大页（THP）
cat /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/enabled

# 数据库建议禁用THP
```

**4. NUMA优化**
```bash
# 查看NUMA配置
numactl --hardware

# 查看进程NUMA使用
numastat -p <pid>

# 绑定进程到NUMA节点
numactl --cpunodebind=0 --membind=0 ./my_program

# 禁用NUMA自动平衡
echo 0 > /proc/sys/kernel/numa_balancing
```

### 磁盘IO优化策略

**1. IO调度器优化**
```bash
# 查看当前IO调度器
cat /sys/block/sda/queue/scheduler
# [mq-deadline] kyber bfq none

# 修改IO调度器
echo deadline > /sys/block/sda/queue/scheduler

# 不同场景推荐：
# - SSD: none (noop) 或 deadline
# - HDD: deadline 或 cfq
# - 数据库: deadline
# - 桌面: cfq

# 永久修改（添加到grub）
# elevator=deadline
```

**2. 文件系统优化**
```bash
# ext4优化挂载选项
mount -o noatime,nodiratime,data=writeback /dev/sda1 /data

# /etc/fstab配置
/dev/sda1  /data  ext4  noatime,nodiratime,data=writeback  0 0

# XFS优化
mount -o noatime,nodiratime,logbufs=8,logbsize=256k /dev/sda1 /data

# 调整预读大小
blockdev --setra 8192 /dev/sda
```

**3. RAID优化**
```bash
# 查看RAID信息
cat /proc/mdstat

# 调整RAID条带大小
mdadm --create /dev/md0 --level=5 --raid-devices=4 \
      --chunk=256 /dev/sd[abcd]1

# 调整RAID重建速度
echo 50000 > /proc/sys/dev/raid/speed_limit_min
echo 200000 > /proc/sys/dev/raid/speed_limit_max
```

**4. 缓存优化**
```bash
# 调整脏页回写参数
# 脏页占总内存的百分比，超过后开始回写
echo 10 > /proc/sys/vm/dirty_ratio

# 后台回写阈值
echo 5 > /proc/sys/vm/dirty_background_ratio

# 脏页存活时间（厘秒）
echo 1500 > /proc/sys/vm/dirty_expire_centisecs

# 回写间隔（厘秒）
echo 500 > /proc/sys/vm/dirty_writeback_centisecs

# 永久配置
cat >> /etc/sysctl.conf << EOF
vm.dirty_ratio = 10
vm.dirty_background_ratio = 5
vm.dirty_expire_centisecs = 1500
vm.dirty_writeback_centisecs = 500
EOF
```

### 性能监控脚本

**系统性能监控脚本**
```bash
#!/bin/bash
# performance_monitor.sh

LOG_FILE="/var/log/performance_monitor.log"
THRESHOLD_CPU=80
THRESHOLD_MEM=80
THRESHOLD_DISK=80

while true; do
    TIMESTAMP=$(date '+%Y-%m-%d %H:%M:%S')
    
    # CPU使用率
    CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
    
    # 内存使用率
    MEM_USAGE=$(free | grep Mem | awk '{printf("%.2f", $3/$2 * 100)}')
    
    # 磁盘使用率
    DISK_USAGE=$(df -h / | tail -1 | awk '{print $5}' | cut -d'%' -f1)
    
    # 记录日志
    echo "$TIMESTAMP CPU:${CPU_USAGE}% MEM:${MEM_USAGE}% DISK:${DISK_USAGE}%" >> $LOG_FILE
    
    # 告警检查
    if (( $(echo "$CPU_USAGE > $THRESHOLD_CPU" | bc -l) )); then
        echo "$TIMESTAMP ALERT: CPU usage is ${CPU_USAGE}%" >> $LOG_FILE
    fi
    
    if (( $(echo "$MEM_USAGE > $THRESHOLD_MEM" | bc -l) )); then
        echo "$TIMESTAMP ALERT: Memory usage is ${MEM_USAGE}%" >> $LOG_FILE
    fi
    
    if [ $DISK_USAGE -gt $THRESHOLD_DISK ]; then
        echo "$TIMESTAMP ALERT: Disk usage is ${DISK_USAGE}%" >> $LOG_FILE
    fi
    
    sleep 60
done
```
