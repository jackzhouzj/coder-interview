## TCP/IP协议栈

### OSI七层模型与TCP/IP四层模型

```
OSI七层模型          TCP/IP四层模型        协议示例
┌─────────────┐
│  应用层      │      ┌─────────────┐
├─────────────┤      │  应用层      │    HTTP, FTP, DNS, SMTP
│  表示层      │      │             │
├─────────────┤      │             │
│  会话层      │      └─────────────┘
├─────────────┤      ┌─────────────┐
│  传输层      │      │  传输层      │    TCP, UDP
├─────────────┤      └─────────────┘
│  网络层      │      ┌─────────────┐
├─────────────┤      │  网络层      │    IP, ICMP, ARP
│  数据链路层   │      └─────────────┘
├─────────────┤      ┌─────────────┐
│  物理层      │      │  网络接口层   │    Ethernet, WiFi
└─────────────┘      └─────────────┘
```

### TCP三次握手与四次挥手

**三次握手（建立连接）**
```
客户端                    服务器
  │                        │
  │──── SYN (seq=x) ──────>│  第一次握手：客户端发送SYN
  │                        │
  │<─── SYN+ACK ──────────│  第二次握手：服务器回复SYN+ACK
  │    (seq=y, ack=x+1)    │
  │                        │
  │──── ACK (ack=y+1) ────>│  第三次握手：客户端发送ACK
  │                        │
  │    连接建立完成         │
```

**四次挥手（断开连接）**
```
客户端                    服务器
  │                        │
  │──── FIN (seq=u) ──────>│  第一次挥手：客户端发送FIN
  │                        │
  │<─── ACK (ack=u+1) ────│  第二次挥手：服务器回复ACK
  │                        │
  │<─── FIN (seq=v) ──────│  第三次挥手：服务器发送FIN
  │                        │
  │──── ACK (ack=v+1) ────>│  第四次挥手：客户端回复ACK
  │                        │
  │    连接断开完成         │
```

## 网络配置管理

### 网络接口配置

**1. 查看网络接口**
```bash
# 查看所有网络接口
ip addr show
ip link show
ifconfig -a

# 查看特定接口
ip addr show eth0
ifconfig eth0

# 查看接口统计信息
ip -s link show eth0
```

**2. 配置IP地址（临时）**
```bash
# 使用ip命令配置
ip addr add 192.168.1.100/24 dev eth0
ip link set eth0 up

# 删除IP地址
ip addr del 192.168.1.100/24 dev eth0

# 使用ifconfig配置
ifconfig eth0 192.168.1.100 netmask 255.255.255.0 up
```

**3. 永久配置（CentOS/RHEL）**
```bash
# 编辑网络配置文件
vi /etc/sysconfig/network-scripts/ifcfg-eth0

# 静态IP配置
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8
DNS2=8.8.4.4

# DHCP配置
TYPE=Ethernet
BOOTPROTO=dhcp
NAME=eth0
DEVICE=eth0
ONBOOT=yes

# 重启网络服务
systemctl restart network
# 或
nmcli connection reload
nmcli connection up eth0
```

**4. 永久配置（Ubuntu/Debian）**
```bash
# 使用netplan（Ubuntu 18.04+）
vi /etc/netplan/01-netcfg.yaml

network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.100/24
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]

# 应用配置
netplan apply

# 传统配置方式（/etc/network/interfaces）
auto eth0
iface eth0 inet static
    address 192.168.1.100
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4
```

### 网络绑定（Bonding）

**配置网卡绑定实现高可用**
```bash
# 加载bonding模块
modprobe bonding

# 创建bond配置（CentOS）
vi /etc/sysconfig/network-scripts/ifcfg-bond0

DEVICE=bond0
TYPE=Bond
BONDING_MASTER=yes
BOOTPROTO=static
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
BONDING_OPTS="mode=1 miimon=100"
ONBOOT=yes

# 配置物理网卡
vi /etc/sysconfig/network-scripts/ifcfg-eth0
DEVICE=eth0
TYPE=Ethernet
BOOTPROTO=none
MASTER=bond0
SLAVE=yes
ONBOOT=yes

vi /etc/sysconfig/network-scripts/ifcfg-eth1
DEVICE=eth1
TYPE=Ethernet
BOOTPROTO=none
MASTER=bond0
SLAVE=yes
ONBOOT=yes

# Bonding模式说明
# mode=0 (balance-rr)    轮询模式，负载均衡
# mode=1 (active-backup) 主备模式，高可用
# mode=2 (balance-xor)   异或模式
# mode=3 (broadcast)     广播模式
# mode=4 (802.3ad)       动态链路聚合
# mode=5 (balance-tlb)   传输负载均衡
# mode=6 (balance-alb)   自适应负载均衡

# 重启网络
systemctl restart network

# 查看bonding状态
cat /proc/net/bonding/bond0
```

## 网络诊断工具

### ping - 测试连通性

```bash
# 基本用法
ping www.google.com

# 指定次数
ping -c 4 www.google.com

# 指定间隔
ping -i 0.5 www.google.com

# 指定包大小
ping -s 1000 www.google.com

# 设置TTL
ping -t 64 www.google.com

# 快速ping（flood ping，需要root）
ping -f www.google.com

# 只显示统计信息
ping -c 10 -q www.google.com
```

### traceroute - 路由追踪

```bash
# 追踪路由
traceroute www.google.com

# 使用ICMP（默认UDP）
traceroute -I www.google.com

# 使用TCP
traceroute -T -p 80 www.google.com

# 不解析主机名
traceroute -n www.google.com

# 设置最大跳数
traceroute -m 20 www.google.com
```

### mtr - 网络诊断工具

```bash
# 综合ping和traceroute
mtr www.google.com

# 报告模式
mtr -r -c 10 www.google.com

# 使用TCP
mtr -T -P 80 www.google.com

# 不解析主机名
mtr -n www.google.com
```

### tcpdump - 网络抓包

```bash

# 抓取特定主机

# 抓取特定端口

# 保存到文件
tcpdump -i eth0 -w capture.pcap

# 读取文件
tcpdump -r capture.pcap

# 显示详细信息
tcpdump -i eth0 -v

tcpdump -i eth0 -vvv

# 显示ASCII内容

# 显示十六进制

# 复杂过滤

# 抓取HTTP请求
tcpdump -i eth0 -A 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12]&0xf0)>>2)) != 0)'
```

## 防火墙配置

### iptables防火墙

**1. 基本概念**
```
iptables四表五链

四表：
- filter表：过滤数据包（默认表）
- nat表：网络地址转换
- mangle表：修改数据包
- raw表：状态跟踪

五链：
- INPUT：入站数据包
- OUTPUT：出站数据包
- FORWARD：转发数据包
- PREROUTING：路由前
- POSTROUTING：路由后
```

**2. 基本操作**
```bash
# 查看规则
iptables -L -n -v
iptables -t nat -L -n -v

# 清空规则
iptables -F
iptables -X
iptables -Z

# 设置默认策略
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许SSH
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 允许特定IP
iptables -A INPUT -s 192.168.1.100 -j ACCEPT

# 拒绝特定IP
iptables -A INPUT -s 192.168.1.200 -j DROP

# 端口转发
iptables -t nat -A PREROUTING -p tcp --dport 8080 -j REDIRECT --to-port 80

# SNAT（源地址转换）
iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -j SNAT --to-source 1.2.3.4

# MASQUERADE（动态SNAT）
iptables -t nat -A POSTROUTING -s 192.168.1.0/24 -o eth0 -j MASQUERADE

# 保存规则
service iptables save
# 或
iptables-save > /etc/sysconfig/iptables

# 恢复规则
iptables-restore < /etc/sysconfig/iptables
```

**3. 常用规则示例**
```bash
#!/bin/bash
# iptables配置脚本

# 清空现有规则
iptables -F
iptables -X
iptables -Z

# 设置默认策略
iptables -P INPUT DROP
iptables -P FORWARD DROP
iptables -P OUTPUT ACCEPT

# 允许本地回环
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许SSH（限制来源）
iptables -A INPUT -p tcp -s 192.168.1.0/24 --dport 22 -j ACCEPT

# 允许HTTP/HTTPS
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 允许ping
iptables -A INPUT -p icmp --icmp-type echo-request -j ACCEPT

# 防止SYN洪水攻击
iptables -A INPUT -p tcp --syn -m limit --limit 1/s --limit-burst 3 -j ACCEPT

# 防止端口扫描
iptables -A INPUT -p tcp --tcp-flags ALL NONE -j DROP
iptables -A INPUT -p tcp --tcp-flags ALL ALL -j DROP

# 保存规则
service iptables save
```

### firewalld防火墙

**1. 基本操作**
```bash
# 启动firewalld
systemctl start firewalld
systemctl enable firewalld

# 查看状态
firewall-cmd --state
systemctl status firewalld

# 查看默认区域
firewall-cmd --get-default-zone

# 查看活动区域
firewall-cmd --get-active-zones

# 查看所有区域
firewall-cmd --get-zones

# 设置默认区域
firewall-cmd --set-default-zone=public
```

**2. 服务管理**
```bash
# 查看允许的服务
firewall-cmd --list-services

# 添加服务
firewall-cmd --add-service=http
firewall-cmd --add-service=https

# 永久添加
firewall-cmd --permanent --add-service=http
firewall-cmd --reload

# 删除服务
firewall-cmd --remove-service=http

# 查看所有可用服务
firewall-cmd --get-services
```

**3. 端口管理**
```bash
# 查看开放端口
firewall-cmd --list-ports

# 开放端口
firewall-cmd --add-port=8080/tcp
firewall-cmd --permanent --add-port=8080/tcp

# 开放端口范围
firewall-cmd --add-port=10000-10100/tcp

# 删除端口
firewall-cmd --remove-port=8080/tcp

# 重载配置
firewall-cmd --reload
```

**4. 富规则**
```bash
# 允许特定IP访问
firewall-cmd --add-rich-rule='rule family="ipv4" source address="192.168.1.100" accept'

# 拒绝特定IP
firewall-cmd --add-rich-rule='rule family="ipv4" source address="192.168.1.200" reject'

# 允许特定IP访问特定端口
firewall-cmd --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" port port="22" protocol="tcp" accept'

# 端口转发
firewall-cmd --add-rich-rule='rule family="ipv4" forward-port port="8080" protocol="tcp" to-port="80"'

# 查看富规则
firewall-cmd --list-rich-rules
```

## 网络故障排查

### 故障排查流程

```
1. 确认问题现象
   ↓
2. 检查物理连接
   ↓
3. 检查网络配置
   ↓
4. 测试网络连通性
   ↓
5. 检查路由和DNS
   ↓
6. 检查防火墙规则
   ↓
7. 分析网络流量
   ↓
8. 解决问题并验证
```

**1. 无法连接网络**

**2. 网络延迟高**

**3. 网络丢包**

### 网络排查脚本

```bash
#!/bin/bash
# network_check.sh - 网络诊断脚本

echo "=== 网络诊断报告 ==="
echo "时间: $(date)"
echo ""

echo "1. 网络接口状态"
ip link show
echo ""

echo "2. IP地址配置"
ip addr show
echo ""

echo "3. 路由表"
ip route show
echo ""

echo "4. DNS配置"
cat /etc/resolv.conf
echo ""

echo "5. 网关连通性"
GATEWAY=$(ip route | grep default | awk '{print $3}')
ping -c 4 $GATEWAY
echo ""

echo "6. 外网连通性"
ping -c 4 8.8.8.8
echo ""

echo "7. DNS解析"
nslookup www.google.com
echo ""

echo "8. 网络连接统计"
ss -s
echo ""

echo "9. 监听端口"
ss -lntp
echo ""

echo "10. 防火墙状态"
if command -v firewall-cmd &> /dev/null; then
    firewall-cmd --list-all
elif command -v iptables &> /dev/null; then
    iptables -L -n
fi
```
