# 分布式系统设计

## 📋 模块概述

本模块涵盖分布式系统设计的核心理论和实践，包括分布式理论、一致性算法、分布式事务、服务治理等高级主题。

## 📚 学习内容

### 1. 分布式理论
- CAP定理
- BASE理论
- 一致性模型
- 分布式时钟
- 向量时钟

### 2. 一致性算法
- Raft算法
- Paxos算法
- ZAB协议
- Gossip协议
- 实现与应用

### 3. 分布式事务
- 2PC两阶段提交
- 3PC三阶段提交
- TCC补偿事务
- Saga模式
- 本地消息表

### 4. 服务治理
- 服务注册与发现
- 负载均衡
- 熔断降级
- 限流控制
- 链路追踪

## 🎯 学习目标

- [ ] 深入理解分布式系统理论

- [ ] 能够设计分布式事务方案
- [ ] 掌握服务治理技术
