# 源码阅读

## 📋 模块概述

本模块通过阅读Go标准库和知名开源项目的源码，深入理解Go语言的设计思想和最佳实践。这是成为Go专家的必经之路。

## 📚 学习内容

### 1. Go标准库源码
- net/http包源码
- context包源码
- sync包源码
- database/sql包源码
- encoding/json包源码

### 2. Gin框架源码
- 路由实现
- 中间件机制
- 参数绑定
- 渲染引擎
- 性能优化

### 3. GORM源码
- 连接池管理
- SQL构建器
- 关联查询
- 钩子机制
- 插件系统

### 4. Kubernetes Go实现
- API Server
- Controller Manager
- Scheduler
- Kubelet
- 核心数据结构
