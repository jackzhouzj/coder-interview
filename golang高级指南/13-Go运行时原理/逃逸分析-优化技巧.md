## 什么是逃逸分析

逃逸分析（Escape Analysis）是 Go 编译器的一项优化技术，用于决定变量应该分配在栈上还是堆上。

### 核心概念

```go
// 栈分配 - 不逃逸
func stackAlloc() {
    x := 42  // x 分配在栈上
    println(x)
}

// 堆分配 - 发生逃逸
func heapAlloc() *int {
    x := 42  // x 逃逸到堆上
    return &x
}
```

### 为什么需要逃逸分析

1. **性能优化**：栈分配比堆分配快得多
2. **减少 GC 压力**：栈上的对象不需要 GC
3. **内存管理**：自动决定最优的内存分配策略

## 逃逸分析原理

### 分析流程

```
源代码 → 编译器前端 → 逃逸分析 → 决策（栈/堆）→ 生成代码
```

### 判断规则

编译器通过以下规则判断是否逃逸：

1. **指针逃逸**：指向栈对象的指针被返回
2. **接口逃逸**：栈对象被赋值给接口
3. **闭包引用**：闭包引用了外部变量
4. **大小超限**：对象太大无法放在栈上
5. **动态类型**：无法在编译期确定大小

## 常见逃逸场景

### 1. 返回局部变量指针

```go
// 逃逸示例
func createUser() *User {
    u := User{Name: "Alice"}  // u 逃逸到堆
    return &u
}

// 不逃逸示例
func createUser() User {
    u := User{Name: "Alice"}  // u 在栈上
    return u
}
```

### 2. 接口类型

```go
// 逃逸示例
func printValue(v interface{}) {
    fmt.Println(v)
}

func main() {
    x := 42
    printValue(x)  // x 逃逸到堆
}

// 优化：使用泛型（Go 1.18+）
func printValue[T any](v T) {
    fmt.Println(v)  // 可能不逃逸
}
```

### 3. 闭包捕获

```go
// 逃逸示例
func createCounter() func() int {
    count := 0  // count 逃逸到堆
    return func() int {
        count++
        return count
    }
}

// 不逃逸示例
func counter() {
    count := 0  // count 在栈上
    for i := 0; i < 10; i++ {
        count++
    }
}
```

### 4. 切片扩容

```go
// 可能逃逸
func appendSlice() []int {
    s := make([]int, 0, 10)
    s = append(s, 1, 2, 3)
    return s  // s 逃逸到堆
}

// 预分配避免逃逸
func appendSliceOptimized(data []int) {
    s := make([]int, 0, len(data))  // 如果不返回，可能不逃逸
    for _, v := range data {
        s = append(s, v)
    }
}
```

### 5. 大对象

```go
// 大对象逃逸
func createLargeArray() {
    arr := [1000000]int{}  // 太大，逃逸到堆
    _ = arr
}

// 小对象不逃逸
func createSmallArray() {
    arr := [10]int{}  // 小对象，在栈上
    _ = arr
}
```

### 6. 动态类型

```go
// 动态大小逃逸
func createSlice(n int) []int {
    return make([]int, n)  // 大小不确定，逃逸到堆
}

// 固定大小不逃逸
func createArray() [10]int {
    return [10]int{}  // 固定大小，在栈上
}
```

## 如何查看逃逸分析

### 使用编译器标志

```bash
# 查看逃逸分析结果
go build -gcflags="-m" main.go

# 查看更详细的信息
go build -gcflags="-m -m" main.go

# 查看内联和逃逸分析
go build -gcflags="-m -l" main.go
```

### 示例输出

```go

type User struct {
    Name string
    Age  int
}

func createUser() *User {

    u := createUser()
```

## 优化技巧

### 1. 避免返回指针

```go
// ❌ 不推荐
func createUser() *User {
    return &User{Name: "Alice"}  // 逃逸
}

// ✅ 推荐
func createUser() User {
    return User{Name: "Alice"}  // 不逃逸
}
```

### 2. 使用值接收者

```go
type Point struct {
    X, Y int
}

// ❌ 指针接收者可能导致逃逸
func (p *Point) String() string {
    return fmt.Sprintf("(%d, %d)", p.X, p.Y)
}

// ✅ 值接收者避免逃逸
func (p Point) String() string {
    return fmt.Sprintf("(%d, %d)", p.X, p.Y)
}
```

### 3. 预分配切片容量

```go
// ❌ 动态扩容可能逃逸
func processData(n int) []int {
    var result []int
    for i := 0; i < n; i++ {
        result = append(result, i)
    }
    return result
}

// ✅ 预分配容量
func processDataOptimized(n int) []int {
    result := make([]int, 0, n)
    for i := 0; i < n; i++ {
        result = append(result, i)
    }
    return result
}
```

### 4. 使用对象池

```go
import "sync"

var userPool = sync.Pool{
    New: func() interface{} {
        return &User{}
    },
}

// ✅ 使用对象池减少堆分配
func processUser() {
    u := userPool.Get().(*User)
    defer userPool.Put(u)
    
    u.Name = "Alice"
    u.Age = 30
    // 处理用户
}
```

### 5. 避免接口装箱

```go
// ❌ 接口装箱导致逃逸
func printAny(v interface{}) {
    fmt.Println(v)
}

// ✅ 使用泛型避免装箱（Go 1.18+）
func printGeneric[T any](v T) {
    fmt.Println(v)
}
```

### 6. 使用数组代替切片

```go
// ❌ 切片可能逃逸
func sumSlice(data []int) int {
    sum := 0
    for _, v := range data {
        sum += v
    }
    return sum
}

// ✅ 数组不逃逸
func sumArray(data [10]int) int {
    sum := 0
    for _, v := range data {
        sum += v
    }
    return sum
}
```

## 实战案例

### 案例 1：字符串拼接优化

```go
// ❌ 多次逃逸
func concatStrings(strs []string) string {
    result := ""
    for _, s := range strs {
        result += s  // 每次都创建新字符串，逃逸
    }
    return result
}

// ✅ 使用 strings.Builder
func concatStringsOptimized(strs []string) string {
    var builder strings.Builder
    builder.Grow(len(strs) * 10)  // 预分配
    for _, s := range strs {
        builder.WriteString(s)
    }
    return builder.String()
}
```

### 案例 2：JSON 序列化优化

```go
import "encoding/json"

type Response struct {
    Code int    `json:"code"`
    Msg  string `json:"msg"`
    Data any    `json:"data"`
}

// ❌ 接口导致逃逸
func createResponse(data interface{}) *Response {
    return &Response{
        Code: 200,
        Msg:  "success",
        Data: data,  // 逃逸
    }
}

// ✅ 使用泛型避免逃逸
func createResponseGeneric[T any](data T) Response {
    return Response{
        Code: 200,
        Msg:  "success",
        Data: data,
    }
}
```

### 案例 3：缓存优化

```go
// ❌ 每次都分配新对象
type Cache struct {
    data map[string]*Item
}

func (c *Cache) Get(key string) *Item {
    if item, ok := c.data[key]; ok {
        return item
    }
    item := &Item{}  // 逃逸
    c.data[key] = item
    return item
}

// ✅ 使用对象池
var itemPool = sync.Pool{
    New: func() interface{} {
        return &Item{}
    },
}

func (c *Cache) GetOptimized(key string) *Item {
    if item, ok := c.data[key]; ok {
        return item
    }
    item := itemPool.Get().(*Item)
    c.data[key] = item
    return item
}
```

## 性能对比

### 基准测试

```go
package main

import "testing"

type Data struct {
    Value int
}

// 返回指针（逃逸）
func createDataPointer() *Data {
    return &Data{Value: 42}
}

// 返回值（不逃逸）
func createDataValue() Data {
    return Data{Value: 42}
}

func BenchmarkPointer(b *testing.B) {
    for i := 0; i < b.N; i++ {
        _ = createDataPointer()
    }
}

func BenchmarkValue(b *testing.B) {
    for i := 0; i < b.N; i++ {
        _ = createDataValue()
    }
}
```

运行结果：
```
BenchmarkPointer-8    50000000    25.3 ns/op    8 B/op    1 allocs/op
BenchmarkValue-8     1000000000    0.5 ns/op    0 B/op    0 allocs/op
```

性能提升：**50 倍**

## 最佳实践

### 1. 设计原则

- 优先使用值类型而非指针
- 小对象使用值传递
- 大对象使用指针传递
- 避免不必要的接口转换

### 2. 代码审查清单

```go
// ✅ 检查清单
// 1. 是否返回了局部变量的指针？
// 2. 是否使用了 interface{} 类型？
// 3. 是否有闭包捕获外部变量？
// 4. 切片是否预分配了容量？
// 5. 是否可以使用对象池？
```

### 3. 性能监控

```go
import (
    "runtime"
    "time"
)

func monitorHeapAlloc() {
    var m runtime.MemStats
    ticker := time.NewTicker(time.Second)
    defer ticker.Stop()
    
    for range ticker.C {
        runtime.ReadMemStats(&m)
        fmt.Printf("Heap Alloc: %d MB\n", m.HeapAlloc/1024/1024)
        fmt.Printf("Heap Objects: %d\n", m.HeapObjects)
    }
}
```

### 4. 工具使用

```bash
# 1. 逃逸分析

# 2. 性能分析
go test -bench=. -benchmem -cpuprofile=cpu.prof

go test -bench=. -benchmem -memprofile=mem.prof

go tool pprof mem.prof
```
