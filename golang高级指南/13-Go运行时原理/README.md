# Go运行时原理

## 📋 模块概述

本模块深入剖析Go语言运行时的核心机制，包括垃圾回收、内存分配、调度器实现等底层原理。这是成为Go高级开发者的必修课。

## 📚 学习内容

### 1. GC垃圾回收
- 三色标记算法
- 写屏障机制
- GC调优技巧
- GC性能分析
- 内存泄漏排查

### 2. 内存分配器
- TCMalloc设计
- mspan、mcache、mcentral
- 内存分配流程
- 逃逸分析
- 内存对齐

### 3. 调度器GMP
- GMP模型详解
- 调度策略
- 抢占式调度
- 系统调用处理
- 调度器演进历史

### 4. 逃逸分析
- 逃逸分析原理
- 常见逃逸场景
- 优化技巧
- 性能影响
- 实战案例
