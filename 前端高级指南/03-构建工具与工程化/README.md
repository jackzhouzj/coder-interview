# 构建工具与工程化

## 学习目标
掌握现代前端工程化体系，熟练使用各种构建工具，建立完整的前端工程化思维。

## 内容概览

### 1. Webpack5
- 核心概念与配置
- Loader与Plugin开发
- 代码分割与优化
- 模块联邦
- 性能优化技巧

### 2. Vite
- 基于ESM的开发服务器
- 快速冷启动原理
- HMR热更新机制
- 生产环境构建
- 插件开发

### 3. Rollup
- ES模块打包
- Tree Shaking原理
- 插件系统
- 库打包最佳实践

### 4. Babel
- AST抽象语法树
- 插件开发
- Preset配置
- Polyfill策略

### 5. ESLint与Prettier
- 代码规范配置
- 自定义规则
- 编辑器集成
- Git Hooks集成

### 6. Monorepo架构
- Lerna使用
- pnpm workspace
- Turborepo
- 依赖管理策略

## 学习路径
1. 从Webpack开始，理解构建工具核心概念
2. 学习Vite，体验现代化开发体验
3. 掌握Babel，理解代码转换原理
4. 配置ESLint/Prettier，建立代码规范
5. 实践Monorepo，管理大型项目

## 实战建议
- 从零搭建项目脚手架
- 优化现有项目构建速度
- 开发自定义Webpack插件
- 搭建企业级Monorepo项目
