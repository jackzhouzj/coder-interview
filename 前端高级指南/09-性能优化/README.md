# 前端性能优化

## 学习目标
掌握前端性能优化的完整体系，能够系统性地分析和优化Web应用性能。

## 内容概览

### 1. 性能指标
- Core Web Vitals
- FCP、LCP、FID、CLS、TTI
- 自定义性能指标
- 性能监控方案

### 2. 加载性能优化
- 资源压缩与合并
- 代码分割与懒加载
- 预加载与预连接
- HTTP缓存策略
- CDN加速

### 3. 运行时性能优化
- JavaScript执行优化
- 渲染性能优化
- 内存管理
- 长列表优化
- 动画性能

### 4. 网络优化
- HTTP/2与HTTP/3
- 资源优先级
- Service Worker
- 离线缓存
- 请求合并

### 5. 构建优化
- Tree Shaking
- Scope Hoisting
- 代码压缩
- 图片优化
- 字体优化

### 6. 性能监控
- Performance API
- 用户体验监控
- 错误监控
- 性能数据上报
- 性能分析工具

## 学习路径
1. 理解性能指标体系
2. 掌握加载性能优化技巧
3. 学习运行时性能优化
4. 实践网络优化方案
5. 建立性能监控体系

## 实战建议
- 使用Lighthouse进行性能审计
- 分析Chrome DevTools性能面板
- 实施渐进式性能优化
- 建立性能预算机制

## 推荐资源
- [Web.dev性能指南](https://web.dev/performance/)
- [Chrome DevTools文档](https://developer.chrome.com/docs/devtools/)
- [Performance API](https://developer.mozilla.org/en-US/docs/Web/API/Performance)
