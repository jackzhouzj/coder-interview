# 网络与安全

## 学习目标
深入理解网络协议和前端安全，掌握HTTP/HTTPS、WebSocket通信，以及XSS、CSRF等常见安全问题的防御方法。

## 内容概览

### 1. HTTP协议
- HTTP基础
- 请求与响应
- 状态码详解
- HTTP/2与HTTP/3
- 性能优化

### 2. HTTPS与SSL
- HTTPS原理
- SSL/TLS握手
- 证书管理
- 安全配置
- 性能优化

### 3. WebSocket
- WebSocket基础
- 连接管理
- 消息通信
- 心跳机制
- 实战应用

### 4. XSS防御
- XSS类型
- 攻击原理
- 防御策略
- CSP配置
- 最佳实践

### 5. CSRF防御
- CSRF原理
- 攻击场景
- Token验证
- SameSite Cookie
- 防御方案

### 6. 前端安全最佳实践
- 输入验证
- 输出编码
- 安全配置
- 依赖管理
- 安全审计

## 学习路径
1. 理解HTTP协议基础
2. 掌握HTTPS加密通信
3. 学习WebSocket实时通信
4. 深入XSS攻击与防御
5. 掌握CSRF防护方法
6. 实践安全开发规范

## 实战建议
- 使用Chrome DevTools分析网络请求
- 配置HTTPS证书
- 实现WebSocket聊天应用
- 模拟XSS/CSRF攻击并防御
- 建立安全开发流程
