### 4. API 安全

- HTTPS 配置
- API 密钥管理
- 防重放攻击

## 💡 学习建议

1. **安全意识优先**：从设计阶段就考虑安全问题
2. **遵循最小权限原则**：只授予必要的权限
3. **永远不信任用户输入**：所有外部输入都要验证
4. **使用成熟的安全库**：不要自己实现加密算法
5. **定期安全审计**：定期检查代码和系统安全性

## ⚠️ 常见安全漏洞

- ❌ SQL 注入：未对用户输入进行过滤
- ❌ XSS 攻击：未对输出进行转义
- ❌ 明文存储密码：未使用哈希算法
- ❌ 硬编码密钥：密钥写在代码中
- ❌ 未加密传输：使用 HTTP 而非 HTTPS

## ✅ 安全最佳实践

- ✅ 使用参数化查询防止 SQL 注入
- ✅ 对所有输出进行转义防止 XSS
- ✅ 使用 bcrypt/argon2 哈希密码
- ✅ 敏感配置使用环境变量
- ✅ 强制使用 HTTPS
- ✅ 实施接口限流和防重放
- ✅ 定期更新依赖库修复安全漏洞
