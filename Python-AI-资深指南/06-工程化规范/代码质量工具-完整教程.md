## 代码质量工具概述

### 为什么需要代码质量工具？

```python
# ❌ 没有工具约束的代码
def calculate(x,y):
    if x>0:
        result=x+y
    else:result=x-y
    return result

# ✅ 使用工具规范后的代码
def calculate(x: int, y: int) -> int:
    """计算两个数的和或差"""
    if x > 0:
        result = x + y
    else:
        result = x - y
    return result
```

### 工具分类

| 工具类型 | 代表工具 | 主要功能 | 优先级 |
|---------|---------|---------|--------|
| 代码格式化 | Black, autopep8 | 自动格式化代码 | ⭐⭐⭐⭐⭐ |
| 代码检查 | Flake8, Ruff | 检查语法和风格问题 | ⭐⭐⭐⭐⭐ |
| 类型检查 | mypy, pyright | 静态类型检查 | ⭐⭐⭐⭐ |
| 代码分析 | pylint, bandit | 深度代码分析 | ⭐⭐⭐⭐ |
| 导入排序 | isort | 自动排序导入语句 | ⭐⭐⭐ |
| Git 钩子 | pre-commit | 提交前自动检查 | ⭐⭐⭐⭐⭐ |

## Black - 代码格式化

### 安装和基本使用

```bash
# 安装
pip install black

# 格式化单个文件
black my_script.py

# 格式化整个目录
black src/

# 检查但不修改（--check）
black --check src/

# 显示差异（--diff）
black --diff src/
```

### Black 配置

```toml
# pyproject.toml
[tool.black]
line-length = 88
target-version = ['py310', 'py311']
include = '\.pyi?$'
extend-exclude = '''
/(
  # 排除的目录
  \.eggs
  | \.git
  | \.hg
  | \.mypy_cache
  | \.tox
  | \.venv
  | _build
  | buck-out
  | build
  | dist
)/
'''
```

### Black 格式化示例

```python
# 格式化前
def very_long_function_name(parameter1,parameter2,parameter3,parameter4,parameter5):
    return parameter1+parameter2+parameter3+parameter4+parameter5

# 格式化后
def very_long_function_name(
    parameter1, parameter2, parameter3, parameter4, parameter5
):
    return parameter1 + parameter2 + parameter3 + parameter4 + parameter5
```

### Black 最佳实践

```python
# ✅ 推荐：让 Black 自动处理格式
def process_data(data: list[dict]) -> list[dict]:
    """Black 会自动格式化这个函数"""
    result = []
    for item in data:
        if item.get("status") == "active":
            result.append(
                {
                    "id": item["id"],
                    "name": item["name"],
                    "value": item["value"],
                }
            )
    return result

# ❌ 避免：手动调整格式（Black 会覆盖）
def process_data(data: list[dict]) -> list[dict]:
    result = []
    for item in data:
        if item.get("status") == "active":
            result.append({"id": item["id"], 
                          "name": item["name"], 
                          "value": item["value"]})
    return result
```

## Flake8 - 代码检查

### 安装和基本使用

```bash
# 安装
pip install flake8

# 检查单个文件
flake8 my_script.py

# 检查整个目录
flake8 src/

# 显示统计信息
flake8 --statistics src/

# 只显示错误数量
flake8 --count src/
```

### Flake8 配置

```ini
# .flake8 或 setup.cfg
[flake8]
max-line-length = 88
extend-ignore = E203, E266, E501, W503
exclude =
    .git,
    __pycache__,
    .venv,
    build,
    dist
max-complexity = 10
```

### 常见 Flake8 错误码

```python
# E501: 行太长
# ❌ 错误
very_long_variable_name = "This is a very long string that exceeds the maximum line length limit"

# ✅ 正确
very_long_variable_name = (
    "This is a very long string that "
    "exceeds the maximum line length limit"
)

# F401: 导入但未使用
# ❌ 错误
import os
import sys  # 未使用

def main():
    print(os.getcwd())

# ✅ 正确
import os

def main():
    print(os.getcwd())

# E302: 函数定义前需要 2 个空行
# ❌ 错误
def function1():
    pass
def function2():
    pass

# ✅ 正确
def function1():
    pass


def function2():
    pass

# W291: 行尾有空白字符
# ❌ 错误
def function():
    return "value"  # 行尾有空格

# ✅ 正确
def function():
    return "value"
```

### Flake8 插件

```bash
# 安装常用插件
pip install flake8-docstrings  # 检查文档字符串
pip install flake8-bugbear     # 检查常见错误
pip install flake8-comprehensions  # 检查列表推导式
pip install flake8-simplify    # 简化代码建议

# 使用插件
flake8 --select=D,B,C,SIM src/
```

## mypy - 类型检查

### 安装和基本使用

```bash
# 安装
pip install mypy

# 检查单个文件
mypy my_script.py

# 检查整个目录
mypy src/

# 严格模式
mypy --strict src/

# 显示错误上下文
mypy --show-error-context src/
```

### mypy 配置

```ini
# mypy.ini 或 setup.cfg
[mypy]
python_version = 3.10
warn_return_any = True
warn_unused_configs = True
disallow_untyped_defs = True
disallow_any_generics = True
check_untyped_defs = True
no_implicit_optional = True
warn_redundant_casts = True
warn_unused_ignores = True
warn_no_return = True
warn_unreachable = True
strict_equality = True

# 忽略特定模块
[mypy-third_party_module.*]
ignore_missing_imports = True
```

### 类型注解示例

```python
from typing import Optional, Union, List, Dict, Callable, TypeVar, Generic

# 基础类型注解
def greet(name: str) -> str:
    return f"Hello, {name}!"

# Optional 类型
def find_user(user_id: int) -> Optional[dict]:
    """可能返回 None"""
    if user_id > 0:
        return {"id": user_id, "name": "User"}
    return None

# Union 类型
def process_value(value: Union[int, str]) -> str:
    """接受 int 或 str"""
    return str(value)

# 列表和字典
def process_data(
    items: List[str],
    config: Dict[str, int]
) -> List[int]:
    return [config.get(item, 0) for item in items]

# 回调函数
def apply_operation(
    value: int,
    operation: Callable[[int], int]
) -> int:
    return operation(value)

# 泛型
T = TypeVar('T')

class Container(Generic[T]):
    def __init__(self, value: T) -> None:
        self.value = value
    
    def get(self) -> T:
        return self.value

# 使用
container: Container[int] = Container(42)
value: int = container.get()
```

### mypy 常见错误

```python
# 错误：参数类型不匹配
def add(a: int, b: int) -> int:
    return a + b

result = add("1", "2")  # error: Argument 1 has incompatible type "str"

# 错误：返回类型不匹配
def get_name() -> str:
    return 123  # error: Incompatible return value type

# 错误：缺少类型注解
def process(data):  # error: Function is missing a type annotation
    return data

# 正确：完整的类型注解
def process(data: list[int]) -> list[int]:
    return [x * 2 for x in data]
```

## pylint - 代码分析

### 安装和基本使用

```bash
# 安装
pip install pylint

# 检查单个文件
pylint my_script.py

# 检查整个目录
pylint src/

# 生成配置文件
pylint --generate-rcfile > .pylintrc

# 只显示特定类型的消息
pylint --disable=all --enable=E,F src/
```

### pylint 配置

```ini
# .pylintrc
[MASTER]
ignore=CVS,.git,__pycache__,.venv
jobs=4

[MESSAGES CONTROL]
disable=
    C0111,  # missing-docstring
    C0103,  # invalid-name
    R0903,  # too-few-public-methods
    R0913,  # too-many-arguments

[FORMAT]
max-line-length=88
indent-string='    '

[DESIGN]
max-args=7
max-locals=15
max-returns=6
max-branches=12
```

### pylint 检查示例

```python
# C0103: 命名不符合规范
# ❌ 错误
MyVariable = 10  # 常量应该全大写
def MyFunction():  # 函数应该小写
    pass

# ✅ 正确
MY_VARIABLE = 10
def my_function():
    pass

# R0913: 参数过多
# ❌ 错误
def create_user(name, email, age, address, phone, city, country, zipcode):
    pass

# ✅ 正确：使用数据类
from dataclasses import dataclass

@dataclass
class UserInfo:
    name: str
    email: str
    age: int
    address: str
    phone: str
    city: str
    country: str
    zipcode: str

def create_user(user_info: UserInfo):
    pass

# W0612: 未使用的变量
# ❌ 错误
def process():
    unused_var = 10  # 定义但未使用
    return 20

# ✅ 正确
def process():
    return 20

# R0201: 方法可以是静态方法
# ❌ 错误
class Calculator:
    def add(self, a, b):  # 未使用 self
        return a + b

# ✅ 正确
class Calculator:
    @staticmethod
    def add(a, b):
        return a + b
```

## isort - 导入排序

### 安装和基本使用

```bash
# 安装
pip install isort

# 排序单个文件
isort my_script.py

# 排序整个目录
isort src/

# 检查但不修改
isort --check-only src/

# 显示差异
isort --diff src/
```

### isort 配置

```toml
# pyproject.toml
[tool.isort]
profile = "black"
line_length = 88
multi_line_output = 3
include_trailing_comma = true
force_grid_wrap = 0
use_parentheses = true
ensure_newline_before_comments = true
skip_gitignore = true
```

### 导入排序示例

```python
# 排序前
import sys
from mypackage import mymodule
import os
from typing import List
from third_party import something

# 排序后（按标准库、第三方库、本地库分组）
import os
import sys
from typing import List

from third_party import something

from mypackage import mymodule
```

## pre-commit - Git 钩子

### 安装和配置

```bash
# 安装
pip install pre-commit

# 初始化（在项目根目录）
pre-commit install

# 手动运行所有钩子
pre-commit run --all-files

# 更新钩子版本
pre-commit autoupdate
```

### pre-commit 配置文件

```yaml
# .pre-commit-config.yaml
repos:
  # Black 代码格式化
  - repo: https://github.com/psf/black
    rev: 23.12.1
    hooks:
      - id: black
        language_version: python3.10

  # isort 导入排序
  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort
        args: ["--profile", "black"]

  # Flake8 代码检查
  - repo: https://github.com/pycqa/flake8
    rev: 7.0.0
    hooks:
      - id: flake8
        args: ["--max-line-length=88", "--extend-ignore=E203"]

  # mypy 类型检查
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.8.0
    hooks:
      - id: mypy
        additional_dependencies: [types-all]

  # 通用钩子
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace  # 删除行尾空白
      - id: end-of-file-fixer    # 确保文件以换行符结尾
      - id: check-yaml           # 检查 YAML 语法
      - id: check-added-large-files  # 防止提交大文件
      - id: check-merge-conflict  # 检查合并冲突标记
      - id: debug-statements     # 检查 debug 语句
```

### pre-commit 工作流

```bash
# 1. 创建配置文件
cat > .pre-commit-config.yaml << EOF
repos:
  - repo: https://github.com/psf/black
    rev: 23.12.1
    hooks:
      - id: black
EOF

# 2. 安装钩子
pre-commit install

# 3. 提交代码时自动运行
git add .
git commit -m "feat: add new feature"
# pre-commit 会自动运行并检查代码

# 4. 如果检查失败，修复后重新提交
git add .
git commit -m "feat: add new feature"

# 5. 跳过钩子（不推荐）
git commit -m "feat: add new feature" --no-verify
```

### 案例 2：修复代码质量问题

import sys,os
from typing import *

def calculate(x,y):
    if x>0:result=x+y
    else:result=x-y
    return result

    def __init__(self,value):

# 运行工具修复

# $ isort my_script.py

# 修复后的代码
import os
import sys
from typing import Any

def calculate(x: int, y: int) -> int:
    """计算两个数的和或差
    
    Args:
        x: 第一个数
        y: 第二个数
    
    Returns:
        如果 x > 0 返回和，否则返回差
    """
    if x > 0:
        result = x + y
    else:
        result = x - y
    return result

    """示例类"""
    
    def __init__(self, value: Any) -> None:
        self.value = value
    
    def get_value(self) -> Any:
        """获取值"""
        return self.value

## 总结

### 工具选择建议

| 场景 | 推荐工具组合 | 说明 |
|------|-------------|------|
| 个人项目 | Black + Flake8 + pre-commit | 基础但够用 |
| 团队项目 | Black + Flake8 + mypy + pre-commit | 加入类型检查 |
| 大型项目 | Black + Flake8 + mypy + pylint + pre-commit | 全面检查 |
| 开源项目 | 全套工具 + CI/CD | 最严格的质量要求 |

### 关键要点

1. **自动化优先**：使用 pre-commit 自动化所有检查
2. **格式化优先**：先用 Black 格式化，再做其他检查
3. **类型注解**：逐步添加类型注解，提高代码质量
4. **持续改进**：定期更新工具版本，学习新特性
5. **团队统一**：确保团队使用相同的配置

### 学习路径

1. 第 1 周：掌握 Black 和 isort
2. 第 2 周：学习 Flake8 和常见错误码
3. 第 3 周：理解 mypy 和类型注解
4. 第 4 周：配置 pre-commit 和 CI/CD
5. 第 5 周：在实际项目中应用

**记住：工具是手段，代码质量是目标！** 💪
