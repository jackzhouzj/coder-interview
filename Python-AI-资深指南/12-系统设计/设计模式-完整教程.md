## 设计模式概述

### 什么是设计模式

设计模式是软件设计中常见问题的典型解决方案。它们就像预先制定的蓝图，可以根据实际需求进行定制。

### 设计模式分类

| 类型 | 目的 | 常用模式 |
|------|------|---------|
| 创建型 | 对象创建机制 | 单例、工厂、建造者、原型 |
| 结构型 | 对象组合方式 | 适配器、装饰器、代理、外观 |
| 行为型 | 对象间通信 | 策略、观察者、责任链、命令 |

### 设计原则（SOLID）

```python
"""
SOLID 设计原则：

1. Single Responsibility Principle (SRP)
   单一职责原则：一个类只负责一个功能

2. Open/Closed Principle (OCP)
   开闭原则：对扩展开放，对修改关闭

3. Liskov Substitution Principle (LSP)
   里氏替换原则：子类可以替换父类

4. Interface Segregation Principle (ISP)
   接口隔离原则：使用多个专门接口，而不是单一总接口

5. Dependency Inversion Principle (DIP)
   依赖倒置原则：依赖抽象，而不是具体实现
"""
```

## 创建型模式

### 1. 单例模式（Singleton）

确保一个类只有一个实例，并提供全局访问点。

#### 使用装饰器实现

```python
def singleton(cls):
    """单例装饰器"""
    instances = {}
    
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    
    return get_instance

@singleton
class DatabaseConnection:
    """数据库连接（单例）"""
    
    def __init__(self, host: str, port: int):
        self.host = host
        self.port = port
        print(f"创建数据库连接: {host}:{port}")
    
    def query(self, sql: str):
        return f"执行查询: {sql}"

# 使用示例
db1 = DatabaseConnection("localhost", 3306)
db2 = DatabaseConnection("localhost", 3306)

print(db1 is db2)  # True，同一个实例
```

#### 使用元类实现

```python
class SingletonMeta(type):
    """单例元类"""
    _instances = {}
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            cls._instances[cls] = super().__call__(*args, **kwargs)
        return cls._instances[cls]

class Logger(metaclass=SingletonMeta):
    """日志记录器（单例）"""
    
    def __init__(self):
        self.logs = []
    
    def log(self, message: str):
        self.logs.append(message)
        print(f"[LOG] {message}")

# 使用示例
logger1 = Logger()
logger2 = Logger()

logger1.log("第一条日志")
logger2.log("第二条日志")

print(logger1 is logger2)  # True
print(logger1.logs)  # ['第一条日志', '第二条日志']
```

#### 线程安全的单例

```python
import threading

class ThreadSafeSingleton:
    """线程安全的单例"""
    _instance = None
    _lock = threading.Lock()
    
    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                # 双重检查锁定
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self):
        if not hasattr(self, 'initialized'):
            self.initialized = True
            print("初始化单例")
```

### 2. 工厂模式（Factory）

定义创建对象的接口，让子类决定实例化哪个类。

#### 简单工厂

```python
from abc import ABC, abstractmethod
from typing import Dict, Type

class Animal(ABC):
    """动物抽象类"""
    
    @abstractmethod
    def speak(self) -> str:
        pass

class Dog(Animal):
    """狗"""
    def speak(self) -> str:
        return "汪汪汪"

class Cat(Animal):
    """猫"""
    def speak(self) -> str:
        return "喵喵喵"

class Cow(Animal):
    """牛"""
    def speak(self) -> str:
        return "哞哞哞"

class AnimalFactory:
    """动物工厂"""
    
    _animals: Dict[str, Type[Animal]] = {
        'dog': Dog,
        'cat': Cat,
        'cow': Cow
    }
    
    @classmethod
    def create_animal(cls, animal_type: str) -> Animal:
        """创建动物"""
        animal_class = cls._animals.get(animal_type.lower())
        if not animal_class:
            raise ValueError(f"未知的动物类型: {animal_type}")
        return animal_class()
    
    @classmethod
    def register_animal(cls, name: str, animal_class: Type[Animal]):
        """注册新的动物类型"""
        cls._animals[name] = animal_class

# 使用示例
dog = AnimalFactory.create_animal('dog')
print(dog.speak())  # 汪汪汪

cat = AnimalFactory.create_animal('cat')
print(cat.speak())  # 喵喵喵
```

### 3. 建造者模式（Builder）

将复杂对象的构建与表示分离，使同样的构建过程可以创建不同的表示。

```python
from typing import Optional

class Computer:
    """电脑"""
    
    def __init__(self):
        self.cpu: Optional[str] = None
        self.memory: Optional[str] = None
        self.storage: Optional[str] = None
        self.gpu: Optional[str] = None
        self.os: Optional[str] = None
    
    def __str__(self) -> str:
        specs = [
            f"CPU: {self.cpu}",
            f"内存: {self.memory}",
            f"存储: {self.storage}",
            f"显卡: {self.gpu}",
            f"系统: {self.os}"
        ]
        return "\n".join(specs)

class ComputerBuilder:
    """电脑建造者"""
    
    def __init__(self):
        self.computer = Computer()
    
    def set_cpu(self, cpu: str) -> 'ComputerBuilder':
        """设置 CPU"""
        self.computer.cpu = cpu
        return self
    
    def set_memory(self, memory: str) -> 'ComputerBuilder':
        """设置内存"""
        self.computer.memory = memory
        return self
    
    def set_storage(self, storage: str) -> 'ComputerBuilder':
        """设置存储"""
        self.computer.storage = storage
        return self
    
    def set_gpu(self, gpu: str) -> 'ComputerBuilder':
        """设置显卡"""
        self.computer.gpu = gpu
        return self
    
    def set_os(self, os: str) -> 'ComputerBuilder':
        """设置操作系统"""
        self.computer.os = os
        return self
    
    def build(self) -> Computer:
        """构建电脑"""
        return self.computer

# 使用示例
computer = (ComputerBuilder()
    .set_cpu("Intel i9-13900K")
    .set_memory("32GB DDR5")
    .set_storage("1TB NVMe SSD")
    .set_gpu("NVIDIA RTX 4090")
    .set_os("Windows 11")
    .build())

print(computer)
```

### 4. 原型模式（Prototype）

通过复制现有对象来创建新对象。

```python
import copy
from typing import List

class Prototype:
    """原型基类"""
    
    def clone(self):
        """浅拷贝"""
        return copy.copy(self)
    
    def deep_clone(self):
        """深拷贝"""
        return copy.deepcopy(self)

class Document(Prototype):
    """文档"""
    
    def __init__(self, title: str, content: str, tags: List[str]):
        self.title = title
        self.content = content
        self.tags = tags
    
    def __str__(self) -> str:
        return f"文档: {self.title}\n内容: {self.content}\n标签: {self.tags}"

# 使用示例
original = Document(
    title="原始文档",
    content="这是原始内容",
    tags=["Python", "设计模式"]
)

# 浅拷贝
shallow_copy = original.clone()
shallow_copy.title = "浅拷贝文档"
shallow_copy.tags.append("教程")

print("=== 原始文档 ===")
print(original)
print("\n=== 浅拷贝 ===")
print(shallow_copy)
print(f"标签是否相同: {original.tags is shallow_copy.tags}")  # True

# 深拷贝
deep_copy = original.deep_clone()
deep_copy.title = "深拷贝文档"
deep_copy.tags.append("进阶")

print("\n=== 深拷贝 ===")
print(deep_copy)
print(f"标签是否相同: {original.tags is deep_copy.tags}")  # False
```

## 结构型模式

### 1. 适配器模式（Adapter）

将一个类的接口转换成客户希望的另一个接口。

```python
from abc import ABC, abstractmethod

# 目标接口
class MediaPlayer(ABC):
    """媒体播放器接口"""
    
    @abstractmethod
    def play(self, filename: str):
        pass

# 被适配的类
class VLCPlayer:
    """VLC 播放器"""
    def play_vlc(self, filename: str):
        print(f"VLC 播放: {filename}")

class MP4Player:
    """MP4 播放器"""
    def play_mp4(self, filename: str):
        print(f"MP4 播放: {filename}")

# 适配器
class MediaAdapter(MediaPlayer):
    """媒体适配器"""
    
    def __init__(self, media_type: str):
        self.media_type = media_type
        
        if media_type == "vlc":
            self.player = VLCPlayer()
        elif media_type == "mp4":
            self.player = MP4Player()
        else:
            raise ValueError(f"不支持的媒体类型: {media_type}")
    
    def play(self, filename: str):
        if self.media_type == "vlc":
            self.player.play_vlc(filename)
        elif self.media_type == "mp4":
            self.player.play_mp4(filename)

# 使用适配器的播放器
class AudioPlayer(MediaPlayer):
    """音频播放器"""
    
    def play(self, filename: str):
        file_type = filename.split('.')[-1].lower()
        
        if file_type == "mp3":
            print(f"MP3 播放: {filename}")
        elif file_type in ["vlc", "mp4"]:
            adapter = MediaAdapter(file_type)
            adapter.play(filename)
        else:
            print(f"不支持的格式: {file_type}")

# 使用示例
player = AudioPlayer()
player.play("song.mp3")
player.play("movie.mp4")
player.play("video.vlc")
```

### 2. 装饰器模式（Decorator）

动态地给对象添加额外的职责。

```python
from abc import ABC, abstractmethod
from functools import wraps
import time

# 使用类实现装饰器模式
class Component(ABC):
    """组件接口"""
    
    @abstractmethod
    def operation(self) -> str:
        pass

class ConcreteComponent(Component):
    """具体组件"""
    
    def operation(self) -> str:
        return "基础功能"

class Decorator(Component):
    """装饰器基类"""
    
    def __init__(self, component: Component):
        self._component = component
    
    def operation(self) -> str:
        return self._component.operation()

class LoggingDecorator(Decorator):
    """日志装饰器"""
    
    def operation(self) -> str:
        result = self._component.operation()
        print(f"[LOG] 执行操作: {result}")
        return result

class TimingDecorator(Decorator):
    """计时装饰器"""
    
    def operation(self) -> str:
        start = time.time()
        result = self._component.operation()
        elapsed = time.time() - start
        print(f"[TIMING] 耗时: {elapsed:.4f}秒")
        return result

# 使用示例
component = ConcreteComponent()
print(component.operation())

print("\n=== 添加日志装饰器 ===")
logged = LoggingDecorator(component)
logged.operation()

print("\n=== 添加多个装饰器 ===")
decorated = TimingDecorator(LoggingDecorator(component))
decorated.operation()

# Python 函数装饰器实现
def log_decorator(func):
    """日志装饰器"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[LOG] 调用函数: {func.__name__}")
        result = func(*args, **kwargs)
        print(f"[LOG] 返回结果: {result}")
        return result
    return wrapper

def timing_decorator(func):
    """计时装饰器"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"[TIMING] {func.__name__} 耗时: {elapsed:.4f}秒")
        return result
    return wrapper

@timing_decorator
@log_decorator
def calculate(x: int, y: int) -> int:
    """计算函数"""
    time.sleep(0.1)  # 模拟耗时操作
    return x + y

# 使用示例
print("\n=== 函数装饰器 ===")
result = calculate(10, 20)
```

### 3. 代理模式（Proxy）

为其他对象提供一种代理以控制对这个对象的访问。

```python
from abc import ABC, abstractmethod
import time

class Subject(ABC):
    """主题接口"""
    
    @abstractmethod
    def request(self) -> str:
        pass

class RealSubject(Subject):
    """真实主题"""
    
    def request(self) -> str:
        print("执行真实请求（耗时操作）")
        time.sleep(1)
        return "真实数据"

class Proxy(Subject):
    """代理"""
    
    def __init__(self):
        self._real_subject: RealSubject = None
        self._cache = None
    
    def request(self) -> str:
        # 延迟初始化
        if self._real_subject is None:
            print("创建真实对象")
            self._real_subject = RealSubject()
        
        # 缓存
        if self._cache is None:
            print("从真实对象获取数据")
            self._cache = self._real_subject.request()
        else:
            print("从缓存获取数据")
        
        return self._cache

# 使用示例
print("=== 代理模式 ===")
proxy = Proxy()

print("\n第一次请求:")
result1 = proxy.request()

print("\n第二次请求:")
result2 = proxy.request()

# 虚拟代理示例：图片加载
class Image(ABC):
    """图片接口"""
    
    @abstractmethod
    def display(self):
        pass

class RealImage(Image):
    """真实图片"""
    
    def __init__(self, filename: str):
        self.filename = filename
        self._load_from_disk()
    
    def _load_from_disk(self):
        print(f"从磁盘加载图片: {self.filename}")
        time.sleep(0.5)  # 模拟加载时间
    
    def display(self):
        print(f"显示图片: {self.filename}")

class ImageProxy(Image):
    """图片代理（虚拟代理）"""
    
    def __init__(self, filename: str):
        self.filename = filename
        self._real_image: RealImage = None
    
    def display(self):
        if self._real_image is None:
            self._real_image = RealImage(self.filename)
        self._real_image.display()

# 使用示例
print("\n=== 虚拟代理 ===")
image = ImageProxy("photo.jpg")
print("图片代理已创建，但图片尚未加载")

print("\n第一次显示:")
image.display()

print("\n第二次显示:")
image.display()
```

### 4. 外观模式（Facade）

为子系统中的一组接口提供一个统一的高层接口。

```python
# 子系统类
class CPU:
    """CPU"""
    def freeze(self):
        print("CPU: 冻结")
    
    def jump(self, position: int):
        print(f"CPU: 跳转到位置 {position}")
    
    def execute(self):
        print("CPU: 执行指令")

class Memory:
    """内存"""
    def load(self, position: int, data: str):
        print(f"内存: 从位置 {position} 加载数据 '{data}'")

class HardDrive:
    """硬盘"""
    def read(self, sector: int, size: int) -> str:
        print(f"硬盘: 从扇区 {sector} 读取 {size} 字节")
        return "boot_data"

# 外观类
class ComputerFacade:
    """电脑外观"""
    
    def __init__(self):
        self.cpu = CPU()
        self.memory = Memory()
        self.hard_drive = HardDrive()
    
    def start(self):
        """启动电脑（简化的接口）"""
        print("=== 启动电脑 ===")
        self.cpu.freeze()
        boot_data = self.hard_drive.read(0, 1024)
        self.memory.load(0, boot_data)
        self.cpu.jump(0)
        self.cpu.execute()
        print("=== 电脑已启动 ===")

# 使用示例
computer = ComputerFacade()
computer.start()  # 一个简单的方法完成复杂的启动过程
```

## 行为型模式

### 1. 策略模式（Strategy）

定义一系列算法，把它们封装起来，并且使它们可以互相替换。

```python
from abc import ABC, abstractmethod
from typing import List

class SortStrategy(ABC):
    """排序策略接口"""
    
    @abstractmethod
    def sort(self, data: List[int]) -> List[int]:
        pass

class BubbleSort(SortStrategy):
    """冒泡排序"""
    
    def sort(self, data: List[int]) -> List[int]:
        print("使用冒泡排序")
        result = data.copy()
        n = len(result)
        for i in range(n):
            for j in range(0, n - i - 1):
                if result[j] > result[j + 1]:
                    result[j], result[j + 1] = result[j + 1], result[j]
        return result

class QuickSort(SortStrategy):
    """快速排序"""
    
    def sort(self, data: List[int]) -> List[int]:
        print("使用快速排序")
        if len(data) <= 1:
            return data
        pivot = data[len(data) // 2]
        left = [x for x in data if x < pivot]
        middle = [x for x in data if x == pivot]
        right = [x for x in data if x > pivot]
        return self.sort(left) + middle + self.sort(right)

class MergeSort(SortStrategy):
    """归并排序"""
    
    def sort(self, data: List[int]) -> List[int]:
        print("使用归并排序")
        if len(data) <= 1:
            return data
        
        mid = len(data) // 2
        left = self.sort(data[:mid])
        right = self.sort(data[mid:])
        
        return self._merge(left, right)
    
    def _merge(self, left: List[int], right: List[int]) -> List[int]:
        result = []
        i = j = 0
        
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                result.append(left[i])
                i += 1
            else:
                result.append(right[j])
                j += 1
        
        result.extend(left[i:])
        result.extend(right[j:])
        return result

class Sorter:
    """排序器（上下文）"""
    
    def __init__(self, strategy: SortStrategy):
        self._strategy = strategy
    
    def set_strategy(self, strategy: SortStrategy):
        """设置策略"""
        self._strategy = strategy
    
    def sort(self, data: List[int]) -> List[int]:
        """执行排序"""
        return self._strategy.sort(data)

# 使用示例
data = [64, 34, 25, 12, 22, 11, 90]

sorter = Sorter(BubbleSort())
print(f"原始数据: {data}")
print(f"排序结果: {sorter.sort(data)}\n")

sorter.set_strategy(QuickSort())
print(f"排序结果: {sorter.sort(data)}\n")

sorter.set_strategy(MergeSort())
print(f"排序结果: {sorter.sort(data)}")
```

### 2. 观察者模式（Observer）

定义对象间的一对多依赖关系，当一个对象状态改变时，所有依赖它的对象都会得到通知。

```python
from abc import ABC, abstractmethod
from typing import List

class Observer(ABC):
    """观察者接口"""
    
    @abstractmethod
    def update(self, subject: 'Subject'):
        pass

class Subject:
    """主题（被观察者）"""
    
    def __init__(self):
        self._observers: List[Observer] = []
        self._state = None
    
    def attach(self, observer: Observer):
        """添加观察者"""
        if observer not in self._observers:
            self._observers.append(observer)
            print(f"添加观察者: {observer.__class__.__name__}")
    
    def detach(self, observer: Observer):
        """移除观察者"""
        if observer in self._observers:
            self._observers.remove(observer)
            print(f"移除观察者: {observer.__class__.__name__}")
    
    def notify(self):
        """通知所有观察者"""
        print(f"通知 {len(self._observers)} 个观察者")
        for observer in self._observers:
            observer.update(self)
    
    @property
    def state(self):
        return self._state
    
    @state.setter
    def state(self, value):
        print(f"状态变更: {self._state} -> {value}")
        self._state = value
        self.notify()

class ConcreteObserverA(Observer):
    """具体观察者 A"""
    
    def update(self, subject: Subject):
        print(f"观察者A 收到通知，新状态: {subject.state}")

class ConcreteObserverB(Observer):
    """具体观察者 B"""
    
    def update(self, subject: Subject):
```

### 3. 责任链模式（Chain of Responsibility）

使多个对象都有机会处理请求，从而避免请求的发送者和接收者之间的耦合关系。

```python
from abc import ABC, abstractmethod
from typing import Optional

class Handler(ABC):
    """处理器接口"""
    
    def __init__(self):
        self._next_handler: Optional[Handler] = None
    
    def set_next(self, handler: 'Handler') -> 'Handler':
        """设置下一个处理器"""
        self._next_handler = handler
        return handler
    
    @abstractmethod
    def handle(self, request: dict) -> Optional[str]:
        """处理请求"""
        if self._next_handler:
            return self._next_handler.handle(request)
        return None

class AuthenticationHandler(Handler):
    """认证处理器"""
    
    def handle(self, request: dict) -> Optional[str]:
        print("1. 认证检查")
        
        if not request.get('authenticated'):
            return "认证失败"
        
        print("   认证通过")
        return super().handle(request)

class AuthorizationHandler(Handler):
    """授权处理器"""
    
    def handle(self, request: dict) -> Optional[str]:
        print("2. 授权检查")
        
        if not request.get('authorized'):
            return "授权失败"
        
        print("   授权通过")
        return super().handle(request)

class ValidationHandler(Handler):
    """验证处理器"""
    
    def handle(self, request: dict) -> Optional[str]:
        print("3. 数据验证")
        
        if not request.get('valid_data'):
            return "数据验证失败"
        
        print("   数据验证通过")
        return super().handle(request)

class ProcessHandler(Handler):
    """业务处理器"""
    
    def handle(self, request: dict) -> Optional[str]:
        print("4. 业务处理")
        return "处理成功"

# 使用示例
```

```python
class Range:
    """自定义范围迭代器"""

        self.end = end

class ReverseIterator:

    def __init__(self, data):
        self.data = data
        self.index = len(data)
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.index == 0:
            raise StopIteration
        self.index -= 1
        return self.data[self.index]
```

### 案例 2：HTTP 请求处理（责任链 + 装饰器）

```python
from abc import ABC, abstractmethod
from functools import wraps
import time

class Middleware(ABC):
    """中间件基类"""
    
    def __init__(self):
        self._next: Middleware = None
    
    def set_next(self, middleware: 'Middleware') -> 'Middleware':
        self._next = middleware
        return middleware
    
    @abstractmethod
    def handle(self, request: dict) -> dict:
        if self._next:
            return self._next.handle(request)
        return request

class LoggingMiddleware(Middleware):
    """日志中间件"""
    
    def handle(self, request: dict) -> dict:
        print(f"[LOG] 请求: {request.get('path')}")
        result = super().handle(request)
        print(f"[LOG] 响应: {result.get('status')}")
        return result

class AuthMiddleware(Middleware):
    """认证中间件"""
    
    def handle(self, request: dict) -> dict:
        print("[AUTH] 检查认证")
        if not request.get('token'):
            return {'status': 401, 'message': '未认证'}
        return super().handle(request)

class RateLimitMiddleware(Middleware):
    """限流中间件"""
    
    def __init__(self):
        super().__init__()
        self.requests = {}
    
    def handle(self, request: dict) -> dict:
        client_ip = request.get('ip')
        print(f"[RATE_LIMIT] 检查 IP: {client_ip}")
        
        # 简化的限流逻辑
        count = self.requests.get(client_ip, 0)
        if count >= 3:
            return {'status': 429, 'message': '请求过于频繁'}
        
        self.requests[client_ip] = count + 1
        return super().handle(request)

class Application:

        self.middleware.set_next(AuthMiddleware()).set_next(RateLimitMiddleware())

        """处理请求"""
        result = self.middleware.handle(request)
        
        if result.get('status') in [401, 429]:
            return result
        
        # 业务逻辑
        return {
            'status': 200,
            'message': '请求成功',
            'data': {'user': 'John'}
        }
```

### 案例 3：事件驱动系统（观察者 + 命令模式）

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Callable
from datetime import datetime

class Event:
    """事件"""
    
    def __init__(self, event_type: str, data: dict):
        self.event_type = event_type
        self.data = data
        self.timestamp = datetime.now()
    
    def __str__(self):
        return f"Event({self.event_type}, {self.data}, {self.timestamp})"

class EventHandler(ABC):
    """事件处理器接口"""
    
    @abstractmethod
    def handle(self, event: Event):
        pass

class EmailHandler(EventHandler):
    """邮件处理器"""
    
    def handle(self, event: Event):
        print(f"[EMAIL] 发送邮件: {event.data.get('to')} - {event.data.get('subject')}")

class LogHandler(EventHandler):
    """日志处理器"""
    
    def handle(self, event: Event):
        print(f"[LOG] 记录事件: {event.event_type} at {event.timestamp}")

class NotificationHandler(EventHandler):
    """通知处理器"""
    
    def handle(self, event: Event):
        print(f"[NOTIFICATION] 推送通知: {event.data.get('message')}")

class EventBus:
    """事件总线"""
    
    def __init__(self):
        self._handlers: Dict[str, List[EventHandler]] = {}
    
    def subscribe(self, event_type: str, handler: EventHandler):
        """订阅事件"""
        if event_type not in self._handlers:
            self._handlers[event_type] = []
        self._handlers[event_type].append(handler)
        print(f"订阅事件: {event_type} -> {handler.__class__.__name__}")
    
    def unsubscribe(self, event_type: str, handler: EventHandler):
        """取消订阅"""
        if event_type in self._handlers:
            self._handlers[event_type].remove(handler)
            print(f"取消订阅: {event_type} -> {handler.__class__.__name__}")
    
    def publish(self, event: Event):
        """发布事件"""
        print(f"\n发布事件: {event}")
        handlers = self._handlers.get(event.event_type, [])
        for handler in handlers:
            handler.handle(event)

# 使用示例
print("\n=== 事件驱动系统 ===")

# 创建事件总线
event_bus = EventBus()

# 创建处理器
email_handler = EmailHandler()
log_handler = LogHandler()
notification_handler = NotificationHandler()

# 订阅事件
event_bus.subscribe("user_registered", email_handler)
event_bus.subscribe("user_registered", log_handler)
event_bus.subscribe("user_registered", notification_handler)

event_bus.subscribe("order_created", log_handler)
event_bus.subscribe("order_created", notification_handler)

# 发布事件
user_event = Event("user_registered", {
    "to": "user@example.com",
    "subject": "欢迎注册",
    "message": "注册成功"
})
event_bus.publish(user_event)

order_event = Event("order_created", {
    "order_id": "ORD123",
    "message": "订单创建成功"
})
event_bus.publish(order_event)
```

## 总结

### 设计模式选择指南

| 场景 | 推荐模式 | 原因 |
|------|---------|------|
| 全局唯一实例 | 单例模式 | 确保只有一个实例 |
| 对象创建复杂 | 工厂模式、建造者模式 | 封装创建逻辑 |
| 动态添加功能 | 装饰器模式 | 不修改原有代码 |
| 接口不兼容 | 适配器模式 | 转换接口 |
| 控制访问 | 代理模式 | 延迟加载、缓存 |
| 算法可替换 | 策略模式 | 算法独立变化 |
| 一对多依赖 | 观察者模式 | 自动通知 |
| 请求处理链 | 责任链模式 | 解耦发送者和接收者 |
| 封装请求 | 命令模式 | 支持撤销、重做 |

### 设计模式最佳实践

1. **不要过度设计**
   - 只在需要时使用设计模式
   - 简单问题用简单方案
   - 避免为了模式而模式

2. **理解模式本质**
   - 掌握模式解决的问题
   - 理解模式的适用场景
   - 知道模式的优缺点

3. **结合 Python 特性**
   - 利用装饰器、上下文管理器
   - 使用生成器、迭代器
   - 发挥动态语言优势

4. **保持代码简洁**
   - 优先使用 Python 内置特性
   - 避免过度抽象
   - 注重代码可读性

### 常见误区

| 误区 | 说明 | 正确做法 |
|------|------|---------|
| 过度使用 | 到处都用设计模式 | 根据实际需求选择 |
| 生搬硬套 | 照搬其他语言的实现 | 结合 Python 特性 |
| 忽视简单性 | 为了模式牺牲可读性 | 保持代码简洁 |
| 不考虑性能 | 过度抽象影响性能 | 平衡设计和性能 |

### 学习路径

1. **基础阶段**（2-3周）
   - 掌握 SOLID 原则
   - 学习常用创建型模式
   - 理解结构型模式基础

2. **进阶阶段**（3-4周）

3. **实战阶段**（4-6周）
   - 在项目中应用模式
   - 重构现有代码
   - 总结最佳实践
