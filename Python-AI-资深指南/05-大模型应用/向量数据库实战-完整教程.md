## 1. 向量数据库核心原理

### 1.1 为什么需要向量数据库

```python
"""
传统数据库 vs 向量数据库：

传统数据库：精确匹配
  SELECT * FROM products WHERE name = 'iPhone'

向量数据库：语义相似度匹配
  "找到与'苹果手机'语义最相似的商品"
  → 返回 iPhone、Apple Watch 等（即使文字不同）

核心能力：
1. 高维向量存储（768维、1536维等）
2. 近似最近邻搜索（ANN）
3. 毫秒级检索（百万/十亿级数据）
4. 元数据过滤
5. 混合搜索（向量 + 关键词）
"""
```

### 1.2 ANN 索引算法

```python
"""
主流 ANN 索引算法：

1. HNSW（Hierarchical Navigable Small World）🔥 最常用
   - 基于图的索引，多层跳表结构
   - 优点：查询速度快，召回率高
   - 缺点：内存占用大
   - 适用：中小规模（< 1000万向量）

2. IVF（Inverted File Index）
   - 基于聚类的索引，先聚类再搜索
   - 优点：内存效率高
   - 缺点：需要训练，召回率略低
   - 适用：大规模数据

3. PQ（Product Quantization）
   - 向量压缩技术，减少内存占用
   - 通常与 IVF 结合使用（IVF-PQ）
   - 适用：超大规模、内存受限

4. DiskANN
   - 基于磁盘的索引
   - 适用：十亿级数据，内存不足时
"""
```

## 2. Qdrant

### 2.1 快速开始

```bash
# Docker 启动
docker run -p 6333:6333 -p 6334:6334 qdrant/qdrant

# 安装 Python 客户端
pip install qdrant-client
```

```python
from qdrant_client import QdrantClient
from qdrant_client.models import (
    Distance, VectorParams, PointStruct,
    Filter, FieldCondition, MatchValue
)

# 🔥 连接 Qdrant
client = QdrantClient(host="localhost", port=6333)

# 创建集合
client.create_collection(
    collection_name="documents",
    vectors_config=VectorParams(
        size=1536,  # OpenAI text-embedding-3-small 维度
        distance=Distance.COSINE
    )
)

# 插入向量
from openai import OpenAI
openai = OpenAI()

texts = [
    "Python 是一种高级编程语言",
    "机器学习是人工智能的分支",
    "Docker 是容器化技术"
]

# 生成 Embedding
embeddings = openai.embeddings.create(
    model="text-embedding-3-small",
    input=texts
)

# 插入数据
points = [
    PointStruct(
        id=i,
        vector=emb.embedding,
        payload={"text": text, "category": "tech"}
    )
    for i, (text, emb) in enumerate(zip(texts, embeddings.data))
]

client.upsert(collection_name="documents", points=points)

# 🔥 搜索
query_embedding = openai.embeddings.create(
    model="text-embedding-3-small",
    input=["什么是 Python？"]
).data[0].embedding

results = client.search(
    collection_name="documents",
    query_vector=query_embedding,
    limit=3
)

for result in results:
    print(f"Score: {result.score:.4f} | {result.payload['text']}")
```

### 2.2 高级功能

## 3. Milvus

### 3.1 快速开始

```bash
# Docker 启动（Standalone 模式）
docker compose -f milvus-standalone-docker-compose.yml up -d

# 安装客户端
pip install pymilvus
```

```python
from pymilvus import (
    connections, Collection, FieldSchema,
    CollectionSchema, DataType, utility
)

# 🔥 连接 Milvus
connections.connect(host="localhost", port="19530")

# 定义 Schema
fields = [
    FieldSchema(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True),
    FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=2000),
    FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=1536),
    FieldSchema(name="category", dtype=DataType.VARCHAR, max_length=100)
]

schema = CollectionSchema(fields, description="文档集合")

# 创建集合
collection = Collection(name="documents", schema=schema)

# 创建索引
index_params = {
    "metric_type": "COSINE",
    "index_type": "HNSW",
    "params": {"M": 16, "efConstruction": 256}
}
collection.create_index("embedding", index_params)

# 插入数据
data = [
    texts,       # text 字段
    embeddings,  # embedding 字段
    categories   # category 字段
]
collection.insert(data)

# 加载到内存
collection.load()

# 🔥 搜索
search_params = {"metric_type": "COSINE", "params": {"ef": 128}}

results = collection.search(
    data=[query_embedding],
    anns_field="embedding",
    param=search_params,
    limit=5,
    output_fields=["text", "category"]
)

for hits in results:
    for hit in hits:
        print(f"Score: {hit.score:.4f} | {hit.entity.get('text')}")
```

## 4. Chroma

```bash
pip install chromadb
```

```python
import chromadb
from chromadb.utils import embedding_functions

# 🔥 Chroma 是最简单的向量数据库
client = chromadb.Client()  # 内存模式

# 持久化模式
client = chromadb.PersistentClient(path="./chroma_db")

# 使用 OpenAI Embedding
openai_ef = embedding_functions.OpenAIEmbeddingFunction(
    model_name="text-embedding-3-small"
)

# 创建集合
collection = client.create_collection(
    name="documents",
    embedding_function=openai_ef
)

# 🔥 添加文档（自动生成 Embedding）
collection.add(
    documents=[
        "Python 是一种高级编程语言",
        "机器学习是人工智能的分支",
        "Docker 是容器化技术"
    ],
    metadatas=[
        {"category": "language"},
        {"category": "ai"},
        {"category": "devops"}
    ],
    ids=["doc1", "doc2", "doc3"]
)

# 🔥 查询（自动向量化查询文本）
results = collection.query(
    query_texts=["什么是 Python？"],
    n_results=3,
    where={"category": "language"}  # 元数据过滤
)

print(results["documents"])
print(results["distances"])
```

### 5.2 pgvector 优势

```python
"""
pgvector 的独特优势：

1. 无需额外基础设施 — 直接在 PostgreSQL 中使用
2. SQL 原生支持 — 可以与业务数据 JOIN 查询
3. 事务支持 — ACID 保证
4. 成熟的运维体系 — 复用 PG 的备份、监控、HA

适用场景：
- 已有 PostgreSQL 的项目
- 向量数据量 < 500 万
- 需要与业务数据关联查询
- 不想引入额外基础设施

示例：向量搜索 + 业务数据 JOIN
"""

# 🔥 向量搜索与业务数据联合查询
sql = """
    SELECT d.text, d.category, u.username,
           1 - (d.embedding <=> %s::vector) AS similarity
    FROM documents d
    JOIN users u ON d.author_id = u.id
    WHERE d.created_at > '2024-01-01'
      AND u.is_active = true
    ORDER BY d.embedding <=> %s::vector
    LIMIT 10
"""
```

```python
import weaviate
from weaviate.classes.config import Configure, Property, DataType

# 🔥 连接 Weaviate
client = weaviate.connect_to_local()

# 创建集合
collection = client.collections.create(
    name="Document",
    vectorizer_config=Configure.Vectorizer.text2vec_openai(),
    properties=[
        Property(name="text", data_type=DataType.TEXT),
        Property(name="category", data_type=DataType.TEXT),
    ]
)

# 🔥 添加数据（自动向量化）
collection.data.insert({
    "text": "Python 是一种高级编程语言",
    "category": "language"
})

# 🔥 混合搜索（向量 + BM25）
results = collection.query.hybrid(
    query="什么是 Python",
    alpha=0.5,  # 0=纯BM25, 1=纯向量
    limit=5
)

for obj in results.objects:
    print(f"{obj.properties['text']}")

client.close()
```

## 9. 性能优化

### 9.1 索引参数调优

```python
"""
HNSW 参数调优指南：

M（连接数）：
- 默认 16，增大提高召回率但增加内存
- 推荐范围：8-64
- 高精度场景：32-64

efConstruction（构建时搜索范围）：
- 默认 128-256，影响索引构建质量
- 推荐范围：100-500
- 越大索引质量越好，但构建越慢

ef（查询时搜索范围）：
- 默认 64-128，影响查询精度
- 推荐范围：50-500
- 越大召回率越高，但查询越慢

经验法则：
- ef >= k（返回结果数）
- efConstruction >= 2 * M
- 先用默认值，根据评估结果调整
"""
```

### 9.2 Embedding 优化

```python
"""
Embedding 选择和优化：

1. 模型选择
   - OpenAI text-embedding-3-small（1536维，性价比高）
   - OpenAI text-embedding-3-large（3072维，精度最高）
   - BGE-M3（多语言，开源）
   - GTE-Qwen2（中文优秀，开源）

2. 维度优化
   - text-embedding-3-small 支持降维到 256/512
   - 降维可减少存储和提升速度，精度损失小

3. 批量处理
   - 批量生成 Embedding，减少 API 调用
   - 使用异步并发提升吞吐
"""

# 降维示例
response = openai.embeddings.create(
    model="text-embedding-3-small",
    input=texts,
    dimensions=512  # 从 1536 降到 512
)
```

## 10. 总结

### 核心要点
1. 向量数据库是 RAG 和 AI 应用的核心基础设施
2. HNSW 是最常用的索引算法，适合大多数场景
3. 选型要考虑数据规模、部署复杂度、功能需求
4. 开发阶段用 Chroma，生产环境用 Qdrant/Milvus
5. 已有 PG 的项目优先考虑 pgvector
